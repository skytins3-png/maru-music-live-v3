MARU MUSIC LIVE V3.2.5 변경사항

1. BIGO 앱 홈 화면만 열리던 V3.2.4 동작을 수정했습니다.
2. 사용자가 허용한 접근성 서비스를 통해 BIGO 홈의 LIVE 버튼을 찾습니다.
3. MARU에서 선택한 일반 LIVE 또는 오디오 LIVE를 BIGO 방송 메뉴에서 자동 선택합니다.
4. 방송 제목·커버·카메라 등을 확인하는 준비 화면에 도착하면 자동 이동을 종료합니다.
5. 실제 공개 방송 시작 버튼은 자동으로 누르지 않습니다.
6. 한국어·영어·중국어·일본어·러시아어 버튼 문구를 인식합니다.
7. 화면 글자 정보가 없는 BIGO 홈 LIVE 버튼에 한해 아래 중앙 위치 탭을 보조 수단으로 사용합니다.
8. BIGO 화면 변경으로 이동에 실패해도 MARU가 종료되지 않고 음악 재생을 유지합니다.
9. 버전 코드 3025, 버전명 3.2.5, GitHub Actions 및 APK 이름을 모두 V3.2.5로 통일했습니다.

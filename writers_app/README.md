# MARU WRITERS STUDIO V1.0 (independent Android APK)
A **standalone** Android app that can be installed alongside MARU RADIO (unique package com.maru.writers.studio.v20261108).
No dependency on installed MARU, no permissions to read or change its private data.
## Features
- 5 distinct editorial role names/IDs WR-01..05 with disjoint singer/host roster check.
- Local deterministic Korean broadcast script outline and 5-role editing steps; not a cloud AI model.
- Optional public Korean Wikipedia search using MediaWiki extracts, on demand only.
- User review/approval required to add evidence to locally stored research notes (max ~30).
- Writer inputs: topic, song title, genre, optional guest singer, approved audience story, optional reviewed sources.
- Editable saved script, manual cue mode, export TXT via Android SAF, share via ACTION_SEND.
- Safe text-only program: no impersonation/voice clone, no TTS, no claimed BIGO broadcasting, no invented real-time news, no crawling beyond user search.
## Restrictions
- No autonomous 5 LLM agents or persistent self-learning model. 5 separate editorial stages are rule-based.
- Wiki excerpts are unverified until operator review and aren't necessarily authoritative; not for live breaking news.
- Selected song isn't played here. Music/Suno/BIGO must be linked and tested separately.
- Android APK is a debug-signed developer preview, not production release.
- INTERNET only; no mic, accessibility, storage permissions or notification listener.

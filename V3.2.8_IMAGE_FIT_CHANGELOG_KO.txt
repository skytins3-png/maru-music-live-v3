MARU MUSIC LIVE V3.2.10 변경사항

1. 분할 화면 하단의 큰 이미지가 위쪽에서 잘리는 문제 수정.
2. 모든 이미지에 FIT_CENTER를 고정 적용해 원본 전체가 보이도록 자동 축소.
3. 세로·가로·정사각형·초대형 이미지 모두 하단 표시 영역 안에 맞춤.
4. 남는 공간은 기존의 흐린 확대 배경으로 채워 검은 여백을 줄임.
5. 전경 이미지에 4dp 안전 여백을 적용해 가장자리 잘림 방지.
6. 버전 3.2.10 / versionCode 3030 / GitHub Actions V3.2.10 통일.

참고: 709x1536 화면의 현재 분할 예시에서 하단 MARU 표시 영역은 약 709x459px, 비율 약 1.54:1입니다. 권장 원본은 1080x700 또는 1540x1000이지만, V3.2.10에서는 다른 크기도 자동 축소됩니다.

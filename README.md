# MARU MUSIC LIVE V3.2.2

## 기본 방송 방식

메인 화면은 `일반 LIVE 음악방송 시작`과 `오디오 LIVE 음악방송 시작` 두 버튼을 우선 제공합니다. MARU는 기존 PlaybackService로 자작곡을 백그라운드 재생하고 BIGO LIVE를 엽니다. 사용자는 BIGO에서 해당 LIVE 종류를 선택하고 `방송하기`를 직접 누릅니다.

이 방식에서는 BIGO 화면에서 기존 청취자의 댓글, 입장, 선물, 팔로우를 직접 확인합니다. MARU가 가짜 마이크·카메라·상점 버튼이나 가짜 댓글을 영상에 그리지 않습니다.

게임 LIVE는 메인 화면에서 제거하고 `오류검사·고급 기능` 안의 보조 모드로 남겨 둡니다.

## 화면 구성

- 일반 LIVE 음악방송 시작
- 오디오 LIVE 음악방송 시작
- 노래·이미지·가사 관리
- 랜덤 재생, 20분 중복 방지, 5개 언어 안내
- 오류검사·고급 기능
- 완전 종료

## 제한

Android 앱이 BIGO의 LIVE 종류나 `방송하기` 버튼을 대신 누르지 않습니다. 일반/오디오 LIVE에서는 MARU의 곡별 이미지와 가사 화면이 청취자에게 송출되지 않으며 BIGO 자체 화면과 커버가 보입니다.

AI 신청곡 거절 정책은 학습으로 바뀌지 않습니다.


## V3.2.2 AI 자동응답 정책

- 입장 알림은 AI 자동답변과 학습에서 제외합니다.
- 입장·좋아요·선물·팔로우는 이벤트 기록으로만 처리합니다.
- 곡이 끝난 뒤에는 기존처럼 다섯 언어 환영 인사와 다음 곡 안내를 재생합니다.
- 일반 댓글의 AI 화면 답변은 한 번에 최대 2초만 표시합니다.
- 신청곡 요청에는 자작곡 방송임을 짧게 설명하고 정중히 거절합니다.
- BIGO 댓글창 자동 입력·전송과 댓글 TTS는 사용하지 않습니다.

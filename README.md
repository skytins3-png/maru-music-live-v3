# MARU MUSIC LIVE V3.2.10

## 핵심 수정

`일반 LIVE 음악방송 시작` 또는 `오디오 LIVE 음악방송 시작`을 누르면 MARU가 자작곡을 백그라운드에서 재생하고 BIGO LIVE를 연 뒤, BIGO 홈 화면의 가운데 LIVE 메뉴와 선택한 방송 종류를 찾아 **방송 준비 화면까지 이동**합니다.

처음 한 번만 Android 접근성 설정에서 `MARU BIGO 방송 화면 이동`을 사용으로 켜야 합니다. 이 서비스는 `sg.bigo.live` 화면만 대상으로 하며 다음 동작만 수행합니다.

- BIGO 홈의 LIVE 진입 버튼 선택
- 일반 LIVE 또는 오디오 LIVE 선택
- BIGO 방송 준비 화면 도착 확인

실제 공개 방송을 시작하는 마지막 `방송 시작/방송하기` 버튼은 안전을 위해 누르지 않습니다. 제목·커버·카메라·마이크 상태를 확인한 뒤 사용자가 직접 시작합니다.

## 화면 구성

- 일반 LIVE 음악방송 시작
- 오디오 LIVE 음악방송 시작
- BIGO 방송 화면 이동 권한 설정
- 노래·이미지·가사 관리
- 랜덤 재생과 20분 중복 방지
- 곡 사이 5개 언어 안내
- 오류검사·고급 기능
- 완전 종료

## 자동 이동 방식

BIGO가 공식 방송 딥링크를 공개하지 않은 경우에도 작동하도록 화면의 글자와 버튼 위치를 함께 확인합니다. BIGO의 한국어·영어·중국어·일본어·러시아어 표기를 인식하며, 글자 정보를 제공하지 않는 가운데 LIVE 버튼은 화면 아래 중앙 위치를 보조 기준으로 사용합니다.

BIGO 업데이트로 화면 구성이 크게 바뀌면 자동 이동이 중단되고 안내 문구를 표시합니다. 이 경우 임의의 최종 방송 시작 버튼을 누르지 않습니다.

## AI 자동응답 정책

- 입장 알림은 AI 자동답변과 학습에서 제외합니다.
- 입장·좋아요·선물·팔로우는 이벤트 기록으로만 처리합니다.
- 곡 종료 후 기존 다섯 언어 환영 인사와 다음 곡 안내를 유지합니다.
- 일반 댓글의 AI 화면 답변은 한 번에 최대 2초만 표시합니다.
- 신청곡 요청에는 자작곡 방송임을 짧게 설명하고 정중히 거절합니다.
- BIGO 댓글창 자동 입력·전송과 댓글 TTS는 사용하지 않습니다.

## 기존 기능 유지 확인

- 신청곡 거절 정책은 학습으로 바뀌지 않습니다.
- `습득·진화 대화형 AI · 작은 화면 답변 · 키보드 없음` 모드를 유지합니다.
- 자동인사에서 `게임 좋아하세요?` 같은 원치 않는 문구는 제외합니다.
- 게임 LIVE 보조 화면에서는 `상단 분할 화면 이미지 좌우 여백 없이 꽉 채우기` 설정을 유지합니다.

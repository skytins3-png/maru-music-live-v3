# MARU VOICE V1.1 (Android native preview)
- On-device microphone DSP, 4 live parameters, 5 voice presets.
- Local mono 48kHz 16-bit WAV recording, playback and user-selected export.
- Uses RECORD_AUDIO only. Foreground only; no network, TTS, AI voice cloning, or sensitive permissions.
- Separate package com.maru.voicefx.v20261108; does not replace MARU RADIO.
- Does NOT feed corrected mic audio into BIGO LIVE; Android inter-app mic injection is not supported here.
- For safe monitoring use wired headphones to avoid acoustic feedback.
- Prototype debug APK is not a production-signed release.

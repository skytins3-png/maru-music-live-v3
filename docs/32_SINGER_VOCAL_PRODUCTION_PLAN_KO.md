## 청취·등록 검증 규칙
1. 매 가수마다 다른 가사로 오리지널 신곡 생성(타인의 원곡·실존 가수 목소리 복제 금지).
2. **같은 가수 2곡에서 음색 일관성**, 다른 가수 2명의 음색 구분, 정확한 발음과 창법, 오토튠·왜곡·저역 과다 여부 청취.
3. Suno에서 자작곡별 **Style Persona를 비공개**로 생성하고 가수 이름을 각각 저장한 뒤 해당 Persona로 새로운 곡 재검증.
4. 보컬/창법/음역이 실제로 다르게 확인된 원본 MP3/WAV만 MARU RADIO에 등록. 원본 재인코딩 없음.
5. 한/중/러 가사 언어는 곡 단위로 지정; 실제 가수 인터뷰 TTS는 한국어로 시작하며 각 국어 TTS 설치/호환성은 별도 확인.
6. 공개 송출권·비공개 음성 소유권·BIGO 정책 검토 후 방송 큐 등록. 실제 가수 프로필 32개 ≠ 가수 음원 32개.

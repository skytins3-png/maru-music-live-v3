# 아환의 음악다방 — MARU RADIO 대화형 음악방송 기획안

상태: 설계 문서. 실제 APK 동작 또는 BIGO 송출 완료를 의미하지 않음.
작성: 2026-10-28

## 방송 방향
1970~90년대 FM 음악방송에서 친근한 DJ의 이야기, 음악 소개, 청취자 소통이라는 보편적 형식만 참고한다.
프로그램명은 **아환의 음악다방**이며 기존 방송사의 로고, 시그널, 멘트, 목소리, 대본, 음악 녹음을 사용하지 않는다.
메인 DJ는 아환, 보조 DJ는 오리지널 AI 캐릭터 윤솔. AI 가수 강태준 등은 음성과 곡이 실제로 제작된 뒤에만 출연한다.

- 00:52~01:00 AI 가수의 작은 방: 가상 캐릭터 대화
- 01:00~01:05 2부 오프닝

시간은 가이드일 뿐 곡이 끝날 때 전환한다. 기본 1시간 자동 종료 없음.

## 곡마다 반복되는 진행
지난 곡 종료 → 아환 소개 15~30초 → 윤솔 질문 8~15초 → 아환 다음 곡 안내 5~10초 → 원본 MP3/WAV 재생 → 마무리 짧은 대화.
음악 구간에는 음성 안내를 기본적으로 넣지 않는다. 사연이 없을 때 허위 사연을 만들어 읽지 않는다.

아환: 오늘도 음악다방에 찾아오신 여러분, 반갑습니다. 노래 한 곡에 담긴 마음을 함께 열어보겠습니다.
윤솔: 오늘은 어떤 음악부터 들려주실 건가요?
아환: 지난 시간을 떠올리게 만드는 우리 창작곡으로 시작하겠습니다.
윤솔: 듣는 사람마다 다른 추억이 떠오르겠네요.
아환: 첫 곡을 함께 듣겠습니다.

## 권리·안전 기준
- 창작곡도 사용허가와 제작 이력이 확인된 파일만 방송 후보로 넣는다.
- Suno 유료 기간 제작 여부, 공식 다운로드 여부, 타인 저작물 포함 여부, 리믹스 여부 및 현재 약관을 확인한다.
- 방송사 시그널, 과거 DJ 멘트, 실제 인물의 음성 복제 및 외부 상업곡을 무단 송출하지 않는다.
- 댓글, 선물, 팔로우는 실제 확인된 내용만 언급한다.
- 로컬 재생과 BIGO 실제 송출은 별도 검증한다. 다른 앱 자동 조작·민감 접근성 권한을 사용하지 않는다.
- AI 캐릭터는 합성 진행자임을 표시한다.

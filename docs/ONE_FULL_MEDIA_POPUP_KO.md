# MARU 한 화면 사진·영상 팝업

## 화면 동작
- 기존 'BIGO와 함께 보기 · 미니 조종창'을 'BIGO와 함께 보기 · 사진/영상 한 화면'으로 변경.
- 팝업 한 화면에 **사진 한 장 또는 영상 하나만** 표시. 곡 제목 목록과 이미지 썸네일은 없음.
- 사진: 비율 유지하며 면적 꽉 차도록 가운데에서 잘라 보이기(CENTER_CROP).
- 영상: 화면에 꽉 차게 확대하고 자동 반복, **영상 오디오만 0으로 음소거**해 MARU 원곡과 방송 멘트를 방해하지 않기.
- 첫 번째 실행 때 기존에 지정한 배경 사진 또는 기본 내장 이미지 표시. 사용자가 선택한 이미지·영상 URI는 앱 환경설정에 한 개만 저장, 원본 파일 자체 업로드 금지.
- 화면을 탭할 때만 '사진·영상 선택 / 음악 재생·정지 / 설정' 버튼이 표시되고 4초 후 자동 숨김.
- 닫기·설정 복귀 시 영상 디코더 및 Surface 해제. 음악 PlaybackService와 별도 동작.
- 로컬 문서 제공자(content://) 또는 앱 제공 리소스만 허용. 네트워크 동영상 주소 자동 가져오기·외부 앱 파일 목록 침범 금지.

## 갤럭시 사용 방법
1. MARU 실행 → '사진·영상 꽉찬 팝업 · BIGO와 함께 보기' 선택.
2. 화면을 한 번 터치 → '사진·영상 선택' → 휴대폰에서 사진 1장 또는 MP4 등 동영상 1개 선택.
3. 손가락으로 화면의 이미지/영상을 확인. 재생 중 필요한 때 화면을 터치하면 선택 메뉴가 잠깐 나타남.
4. 갤럭시 최근 앱에서 MARU 앱 아이콘 → '팝업 화면으로 열기'를 사용하여 BIGO 앱과 나란히 보이는 **기기 지원 팝업 방식**으로 배치.

## 제한
- 현재 구현은 **MARU 앱 창**에 한 장을 보여주는 방식. BIGO가 직접 출력하는 동영상이나 BIGO 시청자가 보는 영상이 자동으로 바뀌는 기능이 아님.
- BIGO 오디오 LIVE 화면은 화면 공유/미디어 합성 송출이 지원되지 않을 수 있으므로 실제 청취자에게 영상 송출된다고 주장할 수 없음. 공식적으로 지원되는 화면 공유 방송 모드에서 별도 검증 필요.
- 다른 앱의 검은 파일 선택기/파일 목록 창은 MARU에서 직접 수정하거나 덮어쓸 수 없음.
- 기존 공개 배포된 설치 APK와 CI 개발 빌드의 서명키가 동일하다는 검증이 없으므로 안전한 제자리 업데이트로 표시하면 안 됨.

# MARU ONE 안드로이드 · 왼쪽 목록 웹 스튜디오 통합

## 사용
- MARU ONE 앱 내부 **🖥 왼쪽 노래목록 · 곡별 사진/영상 스튜디오** 버튼으로 동일 앱 안에서 GitHub Pages MARU Studio를 열도록 개발
- 웹 스튜디오에는 왼쪽 고정 크기/위치 노래 목록과 독립 상하 스크롤, 곡별 이미지·영상 화면 가득 표시, 위/아래/맨 위 순서 변경 기능이 들어 있음
- 웹 안의 '방송 파일 추가'를 사용해 사용 권한이 있는 원곡 MP3/MP4를 선택
- '← MARU' 버튼으로 네이티브 화면 복귀

## 보안과 실질적 제한
- Android WebView의 허용된 사이트 탐색은 `https://skytins3-png.github.io/maru-ai-song-studio/` 경로로 제한
- 바깥 주소는 사용자가 링크를 누른 경우 일반 브라우저로 넘김. 파일, 자바스크립트, 전화 등 비HTTP(S) 스킴은 차단
- 자바스크립트 브리지 없음, 접근성 권한 없음, 외부 앱 화면을 자동으로 누르지 않음
- 웹의 곡과 곡별 영상은 웹뷰 자체 브라우저 저장공간 사용: **현재 안드로이드 MARU 네이티브 MP3 목록과 자동 동기화되지 않음**. 사용자가 각각 파일을 선택해야 함
- 사용자가 웹 라디오를 선택하면 native 플레이어를 일시정지하고 Suno 동반 TTS를 중지해 이중 오디오를 피함
- BIGO 청취자에 대한 실제 오디오 송출, 잠금 화면에서의 지속 재생, 갤럭시의 실제 WebView UX는 물리적 기기로 확인해야 함
- 웹 방송은 외부 사이트 업데이트에 따라 변할 수 있으며 Android APK에 스튜디오 코드를 내장한 오프라인 기능은 아님
- 설치된 MARU ONE V3.2.24에 이 변경이 바로 적용되는 것은 아님. 서명키 유지가 확인되지 않은 새 APK를 기존 버전 위에 덮어쓰기하지 말 것
- 기존 사용자 원곡·설정·웹 데이터를 삭제하거나 이전하지 않음

## 테스트
- Android 단위 테스트로 스튜디오 URL 허용 목록과 위조 URL을 구분
- GitHub CI로 Java 컴파일, 릴리스 APK 빌드, 매니페스트·서명 검사
- 실제 외부 방송 재생 검증은 별도

# MARU 아환 인사영상 · DJ 토크 영상 연결

## 사용 방법 (갤럭시 / MARU 앱)
1. MARU 앱 → **노래·이미지·설정**을 엽니다.
2. **아환 인사 멘트 영상 연결**을 눌러 형이 사용 허락을 가진 인사영상 MP4 등을 선택합니다.
3. **DJ 진행자 토크 영상 연결**을 눌러 토크 때 반복해서 보여줄 MP4 등을 선택합니다.
4. **아환 환영 인사 · 인사영상 지금 실행**을 누르면 기존 휴대폰 영어 TTS가 짧은 원본 환영 문구를 말하는 동안 선택한 인사영상이 나옵니다.
5. **아환 짧은 토크 지금 말하기** 또는 Suno 자동 토크 중 실제 아환·게스트 TTS가 시작되면 토크영상으로 바뀌고, 말이 끝나면 노래별 이미지·영상 또는 기본영상으로 되돌아갑니다.
6. 기존 **곡 사이 안내** 중 입장·선물 등 통합 인사·종료 안내는 인사영상으로, 곡 사이 아환/게스트 대화는 토크영상으로 전환됩니다.
7. 가사가 있는 원곡·사연 화면은 기존 매핑 유지. 승인된 사연 낭독과 일반 DJ 토크가 겹치면 **사연별 영상이 우선**입니다.
8. 선택하지 않은 인사·토크영상은 기존 **기본 MARU 무음 MP4**를 표시합니다. 검은 파일 목록 화면을 만들지 않습니다.

## 화면 전환 우선순위
- 승인된 사연 낭독 → 그 사연에 연결한 사진·영상, 없으면 기본영상
- 아환 인사 멘트(곡 사이 안내/수동 환영) → 아환 인사영상, 없으면 기본영상
- 진행자 대화(TTS 실제 진행 중) → 토크영상, 없으면 기본영상
- 일반 노래 → 해당 곡의 사진·영상, 없으면 기본영상
- 방송 대기 → 기본영상

## 중요한 조건
- 미디어는 본인이 권한을 가진 휴대폰 로컬 파일에서 직접 선택해야 함. 이용자가 올린 미검증 이미지·음원·영상의 자동 재생 금지.
- 영상 소리만 음소거됨. 아환 목소리는 별도의 Android TTS로 재생되며 **입모양·음성 자동 립싱크는 제공하지 않음**.
- 하나의 MARU 팝업 안에서만 영상을 바꿉니다. BIGO 오디오 LIVE 화면 또는 시청자 영상이 자동으로 바뀌는 것은 아닙니다.
- BIGO의 공식 화면 공유/방송 방식이 지원될 때만 시청자 표시 여부를 별도 실기기로 검증합니다.
- 기존 설치 APK와 개발 빌드의 서명키 호환 확인 전에 기존 앱을 삭제하거나 개발 APK로 덮어쓰기 금지.

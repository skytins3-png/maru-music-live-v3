# MARU 노래 보관함 · 국가별/장르별/출처별 모음

## 새 기능
- 앱 설정 상단 **📚 노래 보관함 · 국가별 / 장르별 / 출처별 모음**.
- 분류: 중국노래, 한국노래, 서양노래, 연주곡, 트로트, 발라드, 댄스, 록, 포크, Suno 원곡, 모바일 저장소, MARU 공개곡, 청취자 승인곡, 미분류 및 전체.
- 한 곡은 **국가 1개 + 스타일 1개 + 출처 1개**를 독립적으로 보유합니다. 한국 트로트 곡은 한국과 트로트 양쪽에 표시됩니다.
- 노래를 길게 눌러 실제 국가, 스타일, 출처를 수동 지정할 수 있습니다. 제목에서 자동 추정한 분류는 틀릴 수 있으므로 수동 수정이 최종 기준입니다.
- 모음 → 해당 곡 터치 또는 **모음 전체 연속재생**. 기존 재생 서비스에 안전하게 선택된 부분 대기열을 설정하며, 마스터 목록에서 선택하면 전체 목록으로 복귀합니다.
- 휴대폰 전체 음악 MediaStore 스캔(기존)과 Android 문서 선택(기존)을 유지합니다. Suno 비공개 계정에 몰래 접근하지 않습니다. Suno에서 직접 내려받은 MP3/WAV 또는 공유된 원곡(기존)은 변환하지 않고 보관합니다.
- **MARU 플랫폼 공개 원곡 가져오기**: 실제 배포된, 제작자가 다운로드 허용하고 권리를 확인한 공개곡만 선택해 HTTPS에서 불러온 뒤 원본 바이트를 보관. 한 번에 최대 20개, 곡당 95MiB 한도, 확장자/파일 서명 검사, SHA-256 중복 확인(플랫폼 다운로드 저장 영역). 원격 주소를 임의로 입력할 수 없고 공개 MARU 사이트 이외 URL은 차단합니다.
- 플랫폼 공개곡과 기존 로컬 음악은 모두 동일한 보관함에 추가되고 재생할 수 있습니다.

## 청취자 음원 주의
- 사용자별 공개 신청/첨부파일은 자동으로 가져오거나 플레이하지 않습니다. 청취자곡 분류는 형이 **실제 악성코드·저작권·방송 허가를 확인하고 직접 추가한 로컬 곡**이나 관리자가 공개 catalog.json에 producerApproved/securityVerified/rightsVerified를 모두 기록한 승인곡만을 위한 것입니다. 단순 사용자 자기 신고나 자동 텍스트 검사는 승인이 아닙니다.
- 플랫폼의 **익명 비공개 접수 서버**는 구현 코드만 있고 Cloudflare D1/R2 및 바이러스 검사 서비스가 실제로 배포되지 않았습니다. 따라서 자동 접수 → 검역 → 승인 → 즉시 방송의 전체 워크플로는 아직 실사용이 불가능합니다.
- 공개곡 catalog.json은 현재 빈 배열(0곡). 실제 곡 등록 전에는 자동으로 가져올 수 있는 공개 원곡이 없습니다.
- 비공개 Suno 음원은 Suno 계정 API/접근 권한 없이 자동 다운로드하거나 소리를 가로챌 수 없습니다.

## 방송/업데이트 한계
- 음악 재생은 MARU 앱 안에서 검증할 수 있습니다. BIGO LIVE 청취자 음성/영상 믹서는 공식 연동 및 실제 청취자 기기로 별도 확인해야 합니다.
- GitHub Actions 개발 APK는 기존 배포 앱과 동일 서명키라고 확인되지 않았습니다. 기존 설치 앱을 삭제하거나 개발 APK로 무조건 덮어쓰지 않습니다.
- 로컬 다운로드한 곡은 앱 데이터 영역에 보관되므로 다른 앱/앱 삭제와는 보호 범위가 다릅니다. 백업은 별도로 필요합니다.

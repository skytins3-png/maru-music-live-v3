# MARU MEDIA VAULT 1.0 — 단일 갤럭시 관리 앱 / 비공개 분류

## 기능
- 휴대폰의 노래 폴더(자식 폴더 포함) 또는 표준 ZIP(분할 ZIP이 아닌 일반 ZIP) 대량 가져오기.
- SHA-256 원본 바이트 비교, 동일한 오디오 한 번만 등록. 원본 파일/압축은 삭제·변환하지 않음.
- 예전 107곡 검증목록 JSON을 **휴대폰에서 개별 가져오기**, 등록한 음원 SHA를 원래 제목/언어 그룹에 매칭. PRIVATE JSON을 공개 GitHub에 올리지 않음.
- 한국/중국/서양/일본/검토필요 언어 그룹 + 트로트/발라드/연주 등 수동 장르 분류.
- 곡 상세: 내 기기 미리듣기/내 기기 조회수/내 좋아요/개인 댓글/악보(PDF/사진 첨부, 열기)/파일 로컬 저장.
- 사연: 수동 접수, 승인/거절/방송완료 상태, 선택 파일 첨부.
- HTTPS 서버 설정 + 권리 확인된 곡 일괄 업로드. 미설정 상태에서는 외부로 절대로 송출/게시하지 않음.

## 배포와 주의
- 앱 패키지는 MARU RADIO/작가국과 완전히 별도. 기존 방송 앱 데이터를 지우지 않음.
- 개인 파일 보관함에 비공개로 백업한 105곡 원본은 **공개 웹사이트에 올라간 것이 아님**.
- 서버 API를 실제로 운영해야 다른 청취자가 노래를 듣고 사연을 제출할 수 있음. 이번 단계는 단말 로컬 보관 및 서버 전송 클라이언트.
- 서버와 연결하기 전에는 댓글/좋아요/조회수/사연이 이 기기에만 저장됨. 실시간 BIGO 송출은 이 앱의 기능이 아님.
- 모든 원곡의 Suno 상업적 이용권·저작권·배포권을 게시 전 확인.

# MARU RADIO V1.9.8 — 휴대폰 음소거와 독립적인 RTMP 송출 실험

## 형의 요구
- 건설 현장에서 일하면서 갤럭시 휴대폰 미디어 음량을 0으로 내려도
  **BIGO 시청자에게 Suno 원곡 음악이 계속 적정한 음량으로 들려야 함**.
- 음악·아환 멘트·댓글 자동 답변이 끊김 없이 전달되는 완전형 방송.
- 기존 MARU/BIGO 음악·다국어 DJ·원본 보존·예약/시작/종료·실험 접근성 코드 임의 삭제 금지.

## 공식 지원 경로를 찾은 점
**BIGO 공식 OBS 스트리밍 안내**는 방송자의 계정에
'OBS 스트리밍' 활성화와 **서버 URL 및 스트림 키** 발급 기능이
있다고 설명합니다:
https://www.bigo.tv/ko/bigo-streamer/obs/

따라서 **형의 BIGO 계정에서 이 기능이 보이고 키를 발급할 수 있는 경우에만**
MARU가 BIGO 방송 서버로 오디오/고정 표지를 직접 전송하는 독립 경로를
만드는 것이 가능성이 있습니다. 일반 휴대폰 오디오 LIVE 믹서 모드와는
별도 방식입니다. RTMP 계정이 없는 사용자는 사용할 수 없습니다.

## 새 코드의 실제 역할
- MARU 메인 화면에 **독립 송출 · 휴대폰 음소거에도 RTMP 음악** 버튼 추가.
- 별도 입력 화면에서 소유자가 BIGO 공식 OBS 서버 URL과 스트림 키를
  **자기 휴대폰에서만 입력**합니다. 키는 Preferences, 로그,
  GitHub 및 ChatGPT 서버로 전송·저장하지 않습니다.
  키 입력란은 비밀번호형이며 화면 보안 플래그를 적용했습니다.
- 사용자가 시작 버튼과 확인 버튼을 눌러야만 실제 인터넷 방송을
  시작합니다. 실행할 때 알림이 표시되는 Android 전경 서비스입니다.
  알림에서 즉시 종료할 수 있습니다.
- 오디오 구조:
    `Suno 로컬 MP3/WAV → AudioFileSource(디코더) → RadioRtmpLevelAudioSource
    PCM 평균화/피크 보호 → AAC MediaCodec → RTMP(S) 서버`
  이 경로는 **휴대폰 스피커/마스터 미디어 볼륨을 통과하지 않습니다.**
  송출 휴대폰 음소거 상태에서도 서버로 보내는 디코딩 PCM에 영향이
  없도록 설계했습니다.
- 영상은 카메라 촬영 없이 MARU RADIO 고정 정지 표지를 H.264로
  같이 전송합니다 (일부 RTMP 서버가 비디오를 요구하므로).
- 같은 샘플레이트·스테레오 설정을 가진 곡에 대해 원곡을 연속 재생합니다.
  포맷이 맞지 않는 노래는 건너뛰고, 이어갈 호환곡이 없으면
  송출 서비스를 중지하고 상태를 표시합니다.
- Suno 원본은 절대 변경·압축 재저장하지 않습니다. 송출시 실시간
  PCM gain-riding 및 피크 리미터를 적용하므로 파일 자체의 음질은
  보존됩니다. 엄밀한 LUFS 정규화는 아닙니다.
- 기존 MARU 로컬 음악 플레이어/BIGO 오디오 LIVE 실험 UI/아환
  녹음·댓글 연결 코드를 제거하지 않았습니다.

## 실제 환경 검증 없이는 완료가 아닙니다
1. 형의 BIGO 계정에서 **OBS 스트리밍**을 사용할 수 있는지 확인해야 합니다.
   방송 URL이나 스트림 키 자체는 채팅으로 보내지 마세요.
2. **갤럭시 실제 앱 설치**가 Play 프로텍트 보안 검토에 통과해야 합니다.
   AccessibilityService를 계속 유지했으므로 설치 차단 문제가 그대로 남아 있습니다.
3. 실제 BIGO RTMP 서버 연결 성공과 시청자 화면에서 정상 재생되는지 확인합니다.
4. 다른 폰으로 청취하면서 방송자 폰 미디어 볼륨을 0으로 내립니다.
   음악 소리가 유지돼야 합니다.
5. **아환 TTS/녹음 인사/실시간 댓글 답변은 현재 RTMP 음악으로 합성되지 않습니다.**
   별도 실시간 PCM 보이스 믹서, 오디오 수준 정합과 댓글 수신을
   스트리밍 서비스와 연결하는 다음 구현/검증이 필요합니다.
6. **모든 곡의 샘플레이트가 다르더라도 연속 재생되는 상태가 아닙니다.**
   향후 오디오 PCM 리샘플러가 필요합니다.
7. BIGO 일반 Audio LIVE 믹서에서 노래가 나오리라고 보장할 수 없으며,
   계정마다 OBS 스트리밍 권한/송출 키 발급 정책이 다를 수 있습니다.
8. 예약 없이 즉시 시작하는 별도 RTMP 앱 화면의 실험 구현입니다.
   완전 무인 예약 방송과는 다릅니다.

## 결론
**보안/음량 설계 및 RTMP 송출 코드 구현**과
**실제 BIGO 청취자 송출 성공**을 구분해서 보고해야 합니다.
GitHub CI 빌드가 성공해도 실기기/시청자 테스트 없이는 완성이라고
말할 수 없습니다.

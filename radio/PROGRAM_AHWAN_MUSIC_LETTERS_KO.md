# MARU RADIO 기획안 — 아환의 음악편지 (2026-10-28)

> 콘셉트: 1970–1990년대 음악 라디오의 '사람과 음악이 어울리는 친근함'을 장르적 참고로 삼되, 특정 방송의 **프로그램명·대본·시그널·배경음악·DJ 목소리·상표/로고**를 복제하지 않는 MARU만의 독창적인 음악방송.

## 1. 역사적 레퍼런스 (자료 확인)

- MBC의 옛 '2시의 데이트'는 김기덕 DJ의 오랜 진행, 당시 해외 팝음악 소개와 편안한 대화가 강점이었다.
- 방송에 엽서·사연, 음악에세이, 음악과 극적인 소리를 접목한 실험, 주제별 토크 등을 시도한 것으로 회고된다.
- 마루는 **음악 해설과 청취자와의 친근한 소통이라는 추상적인 제작 원리**만 참고한다. 구체 멘트와 옛 로고·마이크 효과·시그널은 재사용하지 않는다.

## 2. 방송 정체성
- 공식 명칭: **MARU RADIO | 아환의 음악편지**
- 슬로건: **노래가 흐르고, 이야기가 머무는 곳**
- 진행자: 아환(메인, 차분한 한국어 중저음 TTS), 나린(감성 이야기·중국어 겸용), 하온(음악 소개·영어 겸용). 모두 허구 캐릭터.
- 이 앱의 현재 진행자 음성은 기기 TTS 기반이다. 3명의 독립 신경망 가수/모델을 구현했다는 뜻이 아니며, 특정 실존 DJ의 목소리를 모방하지 않는다.
- 기본 음악: 작사/작곡/원본 사용 권한을 확인한 사용자 자작곡, Suno 유료 이용 약관에 따라 적법하게 다운로드한 원곡.
- 4장르: 한국 → 중국 → 서양 → 연주. 장르 비어 있으면 건너뛰고, 곡마다 15~25초 이내의 대화(현재 TTS 성능 및 언어팩에 따라 변동).

## 4. 고유한 프로그램 대본 예시
- **오프닝(아환):** "안녕하세요. 아환의 음악편지입니다. 오늘 하루는 어떤 노래와 함께하셨나요? 여기서는 서두르지 않아도 괜찮습니다. 자작곡 한 곡으로 문을 열겠습니다."
- **나린:** "한 곡을 듣고 나면 문득 오래전 풍경이 떠오를 때가 있어요. 다음 음악에도 누군가의 오늘이 담겨 있겠죠."
- **하온:** "이번 곡은 우리 MARU에서 준비한 새로운 원곡입니다. 제목은 [메타데이터로 확인한 곡명]입니다."
- **중국 인사:** "大家好，欢迎来到马鲁音乐时间。愿音乐陪你度过温柔的时光。"
- **영어 인사:** "Welcome to Maru Radio. We share original music and little stories from the heart."
- **사연 소개:** "방송에 소개해도 된다고 동의해 주신 익명의 청취자께서 보내주셨어요." (사연 없으면 이 코너 생략; 없는 사연을 실제 사연처럼 꾸미지 않음)
- **마무리:** "오늘도 음악편지와 함께해 주셔서 고맙습니다. 다음 노래에서도 만나요."

> 방송 대본은 자체 작성, 대중매체 DJ·방송사 문구의 직접 인용이나 패러디가 아니다. 기존 프로그램의 시그널 멜로디를 연주·리메이크하지 않는다.

## 5. 재생·진행 자동화 설계

1. 저장된 MP3/WAV 원곡 → 파일 변환 없이 읽기 → 저작권 사용확인(곡별 권리 체크) → 재생 허용 목록.
2. 4장르 원곡을 곡당 하나씩 회전; 장르 내 재생 수는 고르게 분배. 동일 SHA-256 원곡 중복 저장 방지.
3. 약 20분 이내 같은 곡 재등장 방지는 *개발 과제*: 재생 시작시간과 파일 해시를 저장해 가능한 대체곡 선택. 곡 수 부족 시 반복 금지 유지/대기 정책을 사용자 설정으로 명시.
4. TTS 방송 진행은 **곡 시작 전에만** 실행. 기존 노래 중간에 TTS를 겹치지 않고 TTS 미지원·실패 시 재생으로 넘어감. TTS와 음악의 실제 송출 균형은 BIGO 외부 믹서 정책에 따라 다름.
5. 진행 대본은 곡마다 6가지 오프닝 × 장르별 4가지 문장 × 곡 소개 4가지 문장으로 순환하며 반복감 감소 (RadioShowLines.java).
6. 시작 예약: 알림 → 사용자 확인 → MARU 재생 + BIGO 앱 열기. 잠금 화면에서 BIGO 생방송 무단 시작 금지.
7. 종료 예약: 명시적으로 켠 타이머만 MARU 재생 종료. 60분 기본 종료 없음. BIGO는 직접 종료.
8. 댓글 자동 응답: BIGO가 적법하고 신뢰 가능한 댓글 접근 API를 제공할 때만 별도 개발. 현재 구현은 수동 입력/복사 답변이며 가짜 자동댓글 주장 금지.
9. 청취자 볼륨: Android 일반 미디어 게인 조절로 BIGO 청취자 볼륨이 독립되지는 않음. BIGO BGM/로컬 파일 입력 기능이 있을 때 별도 청취 장치에서 검증.

## 7. 검증 및 단계

**이미 있는 코드:** Suno 원곡 가져오기, 4장르 순환, TTS 3줄 소개, 사용자 시작 알림, BIGO 앱 이동, 종료 타이머 선택(최신 브랜치), 독창적인 오프닝 변주 대본.

**계획·미구현:** 2시간 코너별 실제 시각 편성, 20분 재생 중복 제한, 실제 30명 AI 보컬/Suno Persona의 생성·검증·연결, 법적 사용허가 UI, 실시간 BIGO 댓글 자동 입력, BIGO 내부 믹서 자동 제어, 방송 청취자 음량 독립.

**시험:** 원곡 다운로드/권한 기록 → 4장르 곡 재생 → 곡 시작 전 대화 → 다른 앱 이동/화면잠금 → 종료 타이머 기본 꺼짐 → 사용자가 명시적으로 켠 종료 타이머 동작 → 별도 청취자 기기로 실제 BIGO 수신 확인.

# MARU RADIO V1.9.3 아환 안전형 — Play 프로텍트 차단 대응

## 차단 원인
2026-10-16 사용자가 올린 설치 화면에는 Google Play 프로텍트가 V1.9.2 아환 DJ 앱을
'민감한 정보에 대한 액세스 권한을 요청할 수 있다'며 차단한 것으로 표시됩니다.
이전 V1.9.2 앱에는 Android `BIND_ACCESSIBILITY_SERVICE` 기반의 서드파티 BIGO 화면 자동 제어 서비스가 Manifest에 포함되어 있었습니다.
이 민감한 구성 요소는 Play 프로텍트 설치 차단의 합리적인 위험 요소입니다.
정확한 위험 판별 요인은 Google Play 프로텍트 내부 분석으로 단정할 수 없습니다.

## 변경
- AndroidManifest.xml에서 AccessibilityService 서비스 등록, `BIND_ACCESSIBILITY_SERVICE` 바인딩과 그 XML 설정 삭제.
- 실제 AccessibilityService 구현과 BIGO 화면 자동 누르기 관련 소스 전체 삭제.
- 예약 시작과 종료가 BIGO 앱을 자동 조작하지 않고 **MARU 원곡 재생/정지 + 명확한 BIGO 직접 조작 알림**으로 처리되도록 변경.
- 방송 설정 화면에서 접근성 권한 동의/설정 진단/자동 조작 안내와 버튼 제거.
- 일반 BIGO 실행 안내와 음악 편성·시간 예약·Suno 원곡 보관·아환 DJ 멘트 언어 정책 유지.
- 다른 앱 ID `com.maru.radio.ahwansafev193`, 버전 `1.9.3-ahwan-safe-preview`로 별도 설치. 기존 버전을 지우지 않아도 됩니다.
- 새 회귀 검사는 소스에 접근성 서비스가 없고 APK Manifest에도 위험한 컴포넌트가 존재하지 않는지 확인합니다.

## 범위와 주의
**V1.9.3은 BIGO 방송 완전 무인 자동 시작/종료 버전이 아닙니다.** BIGO 자체 라이브 버튼과 믹서, 서버 방송 종료는 아직 직접 제어해야 합니다.
아환 AI 진행자 멘트와 Suno 원곡이 BIGO 시청자에게 실제 전달되는지 또한 연결·검증되지 않았습니다.
민감한 접근성 기능을 제거하더라도 Play 프로텍트가 반드시 통과한다고 보장할 수 없으며, 계속 차단되면 재설치 강행하지 말고 차단 상세 메시지를 확인해야 합니다.
**휴대폰 보호 기능을 꺼서 강제로 설치하지 마세요.**
개인용 음악 원본/설정 보호: 기존 MARU 앱과 다른 앱 ID이므로 기존 데이터는 자동 이전되지 않습니다.

## 실기기 설치 확인
1. V1.9.2는 설치가 차단된 상태이므로 진행하지 마세요. Play 프로텍트 끄기 금지.
2. V1.9.3 설치파일만 테스트합니다. 제조사 Android 보안/권한 시스템이 허용하는 경우에만 설치.
3. 앱 권한을 확인해서 접근성 서비스나 다른 앱 화면 읽기 권한을 요청하지 않는지 점검.
4. Suno 원곡을 선택 등록 → 재생 → 곡 변경 → 한국/중국/영어 멘트 → 예약 종료를 실제 휴대폰에서 확인.
5. 만약 V1.9.3도 차단되면 메시지를 찍어 원인을 재점검합니다. 이 경우 설치 시도를 중단합니다.

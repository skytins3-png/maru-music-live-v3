# 아환 AI 아나운서 V1.9.5 — 형이 녹음한 인사가 자동 방송에서 나오지 않는 문제

## 원인
사용자가 보내준 앱 화면에는 **'▶ 녹음된 인사 개인 미리듣기 (자동 방송과 별개)'**라고 적혀 있습니다.
V1.9.4 소스는 녹음파일 URI를 저장했지만 `RadioPlaybackService`의 방송 시작 처리와 곡 시작 처리에서 녹음을 사용하지 않고 영어 Android 시스템 TTS만 불렀습니다.
파일을 고른 뒤에도 실제 자동 시작에서 녹음된 형의 목소리가 나오지 않는 것은 **구현 연결 누락**입니다.

## 수정
- **아환 AI 라디오 아나운서 → 형 목소리로 녹음한 인사 파일 선택**에서 오디오 파일을 선택합니다.
- 저장된 문서 URI가 실제 읽히는지 먼저 검사하고, 장기 읽기 권한을 유지합니다.
- 파일을 고르면 **'영어 녹음 · 자동 시작에 사용'** 또는 **'미리듣기만'** 중 선택할 수 있는 안내창이 표시됩니다.
- **'방송 시작 때 형의 녹음 인사를 재생'** 체크박스를 추가하고 파일 등록/사용 상태를 눈에 보이게 표시합니다.
- 녹음 인사를 자동 시작에 사용하기로 선택하면 **'곡 재생 시작 시 오프닝 멘트'** 옵션도 켜집니다.
- 예약/수동 MARU 방송 시작에서 녹음파일을 우선 재생하고, 그 녹음이 끝나면 장르별 곡 소개 후 보관된 Suno 원곡을 재생합니다.
- 파일이 없거나 Android MediaPlayer 재생 오류가 나면 지정된 **영어 시작 인사 TTS**로 돌아갑니다.
- 녹음 인사 파일 해제 시 자동방송 우선 사용도 꺼지며, Download/개인 녹음 파일 자체는 삭제하지 않습니다.

## 이전 언어 규칙과 충돌 방지
- 방송 시작과 종료는 **영어**로 한다고 형이 정했으므로, 자동 재생에 연결할 개인 녹음 인사 파일도 **영어로 직접 녹음한 음성**이어야 합니다.
- 한국어로 녹음한 인사는 개인 미리듣기로 들을 수 있지만, 영어 오프닝 규칙을 지키려면 영어 인사를 따로 녹음해야 합니다.
- 별도 **음성 복제 모델이 아니므로** 녹음된 인사말만 형 목소리 그대로 재생됩니다. 그 녹음파일 하나로 다른 문장(곡 소개/댓글 응답)을 형 목소리로 합성할 수는 없습니다.
- 한국곡 소개: 한국어→영어, 중국곡: 중국어→영어, 영어곡·연주곡: 영어. 선물: 고객 입력 언어(모르면 영어). 종료: 영어는 유지합니다.

## 남아 있는 실제 기기 확인
- 앱에서 녹음 인사가 실제로 재생되고, 등록 음성을 자동 시작에 선택했을 때 오프닝에 사용되는지 갤럭시에서 확인해야 합니다.
- BIGO 자동 버튼 조작 코드는 V1.9.4 브랜치 그대로 **유지**했습니다. 그러나 Google Play 프로텍트 설치 차단과 BIGO 실제 청취자 음성 송출은 아직 해결·검증되지 않았습니다.
- 접근성 기능 APK를 직접 내려받아 강제로 설치하거나 Play 프로텍트를 해제하는 방법은 권유하지 않습니다. 서명된 Google Play 배포는 Play Console 심사를 거쳐야 합니다.

## 사용 테스트
1. **AI 아나운서** 화면에서 파일 선택 → 형 목소리로 녹음된 영어 파일을 고릅니다.
2. **영어 녹음 · 자동 시작에 사용**을 선택합니다. 화면에 '인사 녹음: 등록됨 / 자동 오프닝: 형 목소리 사용 / 방송 시작 인사: 켜짐'이라고 나와야 합니다.
3. '형의 녹음 인사 실제 소리 미리듣기' 버튼으로 그 파일이 정상 재생되는지 확인합니다.
4. MARU 원곡을 새로 재생합니다. 인사 → 곡 소개 → 원곡이 나와야 합니다.
5. 파일 재생 실패 시 영어 TTS로 이어지는지, 노래가 멈추지 않는지 확인합니다.

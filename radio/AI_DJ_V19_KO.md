# MARU RADIO V1.9.1 — 아환 AI 아나운서 미리보기

진행자 정식 이름: **아환 아나운서**. 인사·곡 소개·종료 멘트 및 앱 화면에서 이 이름을 사용합니다.

## 구현
- 메인화면 **🎙 AI 라디오 아나운서 · 인사/댓글/신청곡** 에서 별도 진행자 화면 열기.
- MARU 자체 음악 재생 중 곡 시작 전에 **오프닝/다음 곡 소개** 멘트 (각 옵션 기본값 **끔**). TTS 멘트가 끝난 후 원곡 그대로 재생; 곡 완료시 다음 곡도 소개 가능.
- 오프닝, 다음 곡, 장미·선물 감사, 팔로우 감사, 마무리 멘트.
- 사용자가 댓글을 **직접 입력/붙여넣기**하면 로컬 규칙이 상황에 맞춰 답변. 정확한 제목의 요청곡은 등록한 Suno 원곡 중 검색해 소개 멘트 후 재생. 중복·애매한 곡명은 임의 선택하지 않음.
- **음성으로 질문** 버튼은 Android에 설치된 음성 인식 앱을 사용하며 화면 표시된 입력을 사용자가 직접 시작. MARU는 `RECORD_AUDIO` 권한을 요청하지 않음. 인식 앱 제공자에 따라 음성이 외부 처리될 수 있음.
- 휴대폰에 설치된 음성 엔진을 통한 **한국어/중국어/영어/일본어/러시아어** 멘트 (해당 언어 TTS 데이터가 설치되어야 함). 대화 생성은 주로 한국어 기반의 한정된 **로컬 규칙 엔진**이고, 인터넷에 연결하는 생성형 LLM이 아님.
- **형 목소리**: 휴대폰 문서 선택기에서 **형이 직접 녹음한 인사 MP3/WAV**를 선택하면 그 녹음 음성을 오프닝으로 재생. 실제로 형의 목소리를 새 문장으로 복제하거나 새로운 노래를 가창하는 모델은 포함되지 않음.
- 직접 가르친 '키워드→응답' 문구 최대 20개. '학습'을 별도로 활성화하면 곡 신청 횟수/응답 횟수만 로컬 보관하고, 응답 텍스트·시청자 이름·BIGO 댓글은 보관하지 않음. 모든 학습 기록 지우기 가능.
- 노래 자체는 Suno에서 받은 **원본 MP3/WAV**를 로컬 MediaPlayer에서 재생. 오디오 재인코딩 없음.

## 사용 순서
1. 형의 기존 앱을 삭제하지 마세요. V1.9 미리보기는 기존 CI debug 서명 충돌을 피하려고 다른 앱 ID로 설치됩니다. 기존 앱의 개인 폴더 음악/설정은 자동 이전되지 않습니다.
2. 기존 Download/Music 폴더의 Suno 원곡을 V1.9에 다시 등록합니다.
3. MARU RADIO → **🎙 AI 라디오 아나운서** → **시스템 음성 사용** 켜기.
4. 원하면 **곡마다 다음 곡 소개**와 **곡 재생 시작 시 오프닝 멘트**를 켭니다.
5. **형의 목소리로 녹음한 인사 파일 선택** 버튼에서 형이 직접 녹음한 음원만 고릅니다. 형의 목소리를 새 문장으로 합성하는 것과 다릅니다.
6. 예: 댓글에 `가을 남자 노래 틀어줘` → **대화 답변하고 읽어주기** → 제목이 유일하게 일치하면 원곡 신청/소개/재생.
7. `고마워`, `팔로우했어요` 같은 문장 답변은 TTS로 읽습니다. 원하는 답변을 **직접 가르치기**로 교정할 수 있습니다.

## BIGO 통합의 현실적 한계
- 방송 시청자 댓글, 닉네임, 선물 이벤트를 BIGO에서 **자동 수집하거나 자동 댓글을 전송하는 API가 연결되지 않았습니다**. 사용자가 직접 입력한 댓글에만 답변할 수 있습니다.
- 휴대폰의 TTS/음악 소리가 BIGO 라이브의 방송 오디오 입력으로 전달되는지 **아직 증명되지 않았습니다**. MARU 로컬 음성 재생은 BIGO 시청자가 듣는 방송음을 뜻하지 않습니다.
- `마이크=1`, BIGO 실제 오디오 라이브 시작/종료 제어도 현재 V1.8 접근성 실험으로만 존재합니다. V1.9는 실험 브랜치를 기반으로 하는 **사전 검증용 기능**이며 정식 방송 자동화 완성판은 아닙니다.
- BIGO의 화면·시청자 오디오·방송 서버 종료는 실제 갤럭시 S26 울트라 및 별도 청취 기기로 검증해야 합니다. Play Protect 경고나 권한 제한 우회 금지.

## 개발 검증
- `scripts/RadioDjBrainSelfTest.java`: 오프라인 대본, 유일/중복 원곡 검색, 댓글 응답 및 입력 위생.
- `scripts/test_radio_contract.py`: 안드로이드 TTS, 로컬 학습·개인정보 보관 금지, 안내 음성·원곡 순서 검증.
- GitHub Actions `build-radio.yml`: JVM 테스트 + Android lint, debug/release 빌드, 서명·앱 ID 확인.
- Android 시스템에서 **실제 형 음성 신경망 합성**을 제공하려면 형의 녹음 동의 및 음성 샘플, 별도 지원되는 음성 합성 엔진과 개인용 안전한 배포 구성이 추가로 필요합니다.

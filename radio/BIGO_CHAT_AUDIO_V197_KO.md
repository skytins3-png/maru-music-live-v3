# MARU RADIO V1.9.7 — BIGO 댓글 자동 감지와 청취자 오디오 연결 상태

## 사용자가 요청한 완성 조건
1. 형이 BIGO에서 일하는 동안 실제로 올라온 청취자 댓글을 아환이 자동으로 읽고 해당 고객 언어로 답한다.
2. 아환의 답변과 Suno 음악이 BIGO **서버 방송 입력**으로 전달되어 다른 휴대폰 청취자에게 일정한 음량으로 들린다. 형의 휴대폰 스피커는 음소거해도 청취자는 소리를 듣는다.

## V1.9.7에 실제 구현한 부분
- 기존 BIGO 자동화 접근성 서비스·음악·녹음된 형의 인사·예약·분류·음량 균일화는 삭제하거나 끄지 않았습니다.
- 아환 DJ 화면에 **'BIGO 방송 댓글 자동 읽기·짧은 음성 답변 허용'**을 별도로 선택·철회할 수 있는 명시적 동의 UI를 추가했습니다. 최초 설정은 꺼짐입니다.
- BIGO 패키지 `sg.bigo.live`의 **호스트 LIVE 상태가 확인되고** 실제 화면의 채팅 관련 위젯(View resource id에 chat/comment/danmu 등 표시)이 감지된 경우에만 이름:댓글 형태로 온 짧은 텍스트를 일시적으로 처리합니다.
- 개인식별 닉네임이나 채팅 문장 원문을 디스크·네트워크·로그에 저장하지 않습니다. 메모리에 댓글 지문 최대 80개만 유지하다 꺼지면 비웁니다.
- 처음 확인한 채팅 화면은 이전 댓글을 음성으로 뒤늦게 읽지 않도록 초기화만 합니다. 그 후 새로 나온 인사/감사/선물 관련 제한된 메시지만 **15초에 최대 1개** 짧게 한국·중국·영·일·러시아어 TTS로 처리합니다.
- 날씨·뉴스·개인정보·관계·결제·자유질문에 대한 무검증 답변은 하지 않습니다. BIGO 댓글창에 텍스트를 자동 게시하지 않습니다.
- 보안/잠금 화면, BIGO 아닌 화면, 방송 준비 단계, 접근성 미허용에서는 읽지 않습니다.
- 음악+아환 시스템 TTS+형이 녹음한 영어 인사의 Android AudioAttributes를 media usage / allowable audio capture로 선언했습니다. **다른 앱이 사용자 동의를 거쳐 Android AudioPlaybackCapture를 구현해야만** 실제로 오디오를 캡처할 수 있습니다.
- BIGO 오디오 출력 경로 점검 안내 버튼을 추가했습니다. 수신 확인은 다른 휴대폰에서 실제로 해야 합니다.

## 아직 완료되지 않은 부분 (완료라고 주장하면 안 됨)
- 현재 댓글 감지는 BIGO의 **실제 갤럭시 S26 Ultra 호스트 화면 접근성 트리**를 읽어본 적이 없습니다. BIGO가 댓글을 사용자에게 표시하더라도 `AccessibilityNodeInfo`의 관련 위젯이 표시되지 않으면 자동응답을 못 할 수 있습니다.
- 현재 답변은 고정된 간단한 인사/감사/선물 패턴 위주로 제한되어 있어 **자유롭게 모든 질문에 AI 답변하는 기능이 아닙니다**.
- 휴대폰에서 아환 TTS가 재생될 뿐, **BIGO 오디오 LIVE의 라이브 마이크/믹서로 PCM을 주입하는 승인된 Android/BIGO 연결은 구현되지 않았습니다.**
- 일반 Android 앱은 다른 앱의 마이크 신호를 마음대로 바꿀 수 없습니다. `AudioPlaybackCapture`는 **BIG0 같은 수신 앱이 자발적으로 캡처하도록 허용하는 기능**이지 송출 앱이 BIGO 마이크를 조작하는 기능이 아닙니다.
- BIGO 내부 BGM 메뉴로 **그 서비스가 지원하는 로컬 음악을 전송**하는 방식은 가능성을 조사할 수 있지만, 형의 음악·아환의 수시 답변을 같은 동적 오디오 버스로 자동 혼합하는 API는 아직 확인되지 않았습니다.
- Play 프로텍트에서 민감한 접근성 API가 포함된 개발용 APK를 차단한 이슈도 해결되지 않았습니다. 디버그 빌드를 강제로 설치하거나 보호 기능을 끄도록 안내하지 않습니다.

## 공식 문서에서 확인된 접속 조건
- BIGO LIVE 관련 공개된 Open Platform 문서에는 *danmu(탄막) 게임* API를 통해 댓글/선물 데이터를 받는 기능이 등장합니다. 하지만 일반 사용자 ID만으로 자유롭게 쓰는 API가 아닙니다. 제휴용 AppID / game_id / 게임 세션 / 승인된 OAuth 토큰이 필요합니다.
- BIGO의 오디오 LIVE 도움말은 믹서의 **BGM** 메뉴를 설명하지만 이 메뉴가 형의 MARU 내부 플레이어나 TTS를 외부 입력으로 받는다고 주장하지 않습니다.
- Android 공식 문서는 AudioPlaybackCapture 사용에 **수신 앱 구현과 사용자 MediaProjection 동의** 등이 필요하다고 설명합니다.
- 참고: https://github.com/yothen/Bigo-Open-Api/blob/main/danmu_data_api_cn.md
- 참고: https://developer.android.com/media/platform/av-capture?hl=ko
- 참고: https://www.bigo.tv/ko/blog/audio-live-bigo-live

## 실제 완성 확인에 필요한 자료
1. BIGO 방송 중 **댓글이 보이는 호스트 화면** (실제 사람 이름은 가리고 보내도 됩니다), 그리고 MIXER/BGM/음악 추가 메뉴의 실제 화면.
2. 안드로이드 접근성 서비스에서 해당 댓글 위젯의 식별자가 나오는지 동의 하에 테스트.
3. **별도 청취자 휴대폰**으로 형 휴대폰 음량 0 상태에서 음악과 아환의 소리가 들리는지 검증.
4. 가능하면 BIGO에서 승인된 Open Platform 권한 또는 외부 음성 입력/송출 SDK·스트림 키 지원을 공식적으로 확인.

## 개발물 제공 범위
V1.9.7은 **서드파티 BIGO 댓글 UI 읽기 + 휴대폰 TTS 답변 실험판**, **오디오 캡처 허용 설정/송출 진단용**입니다. 사용자 요청 2개 모두 실방송 사용 가능하다고 확정할 수 없습니다.

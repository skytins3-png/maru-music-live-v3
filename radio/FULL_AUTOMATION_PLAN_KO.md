# MARU RADIO 최종 목표: 오디오 LIVE 자동 방송 운영

## 사용자 목표 / 실제 완료 판정 조건

1. 사용자는 Suno **원곡 그대로** 다운로드 폴더에서 수백 곡을 등록한다. 같은 음악의 동일 바이트는 1곡만 남긴다.
2. 방송 편성에서 **한국노래 / 중국노래 / 서양노래 / 연주곡**을 선택하거나 조합하고, 원곡 편성 순서를 정한다. 각 장르별 예약 슬롯과 랜덤 중복방지·자동 다음 곡을 지원한다.
3. 미래 방송 시작일시와 종료일시 또는 방송 길이(예: 60분)를 입력한다. 시작 시 BIGO 오디오 라이브에 정상적으로 접속하고 종료 시 **실제 방송 종료를 외부 관측**으로 확인한다. BIGO가 앱 간 방송 제어 API를 제공하지 않는다면 화면 접근성은 불안정한 대안이므로 무인 완전 자동 방송을 보장하지 않는다.
4. 음악 재생 음량과 물리 볼륨 버튼을 **방송 송출 음량과 독립적으로** 유지한다. 최소 마이크 1을 설정하는 UI와 음악 송출은 별개다. BIGO 공식 로컬 오디오/BGM 믹서 또는 공식 외부 송출 인터페이스로 오디오를 직접 입력받을 수 있는지 검증해야 한다. 그렇지 않으면 수신측 음량 고정은 달성할 수 없다.
5. 라이브 댓글(입장, 일반 대화, 선물, 좋아요, 팔로우)을 이벤트로 받아서 한국/중국/영어/일본/러시아어의 자연스러운 짧은 응답을 만든다. 댓글의 개인정보·중복·불쾌한 말·민감한 내용은 과잉 발화하지 않는다. 사용자는 자동 대화 여부 및 비상 정지 기능을 켜고 끌 수 있다.
6. 음성 답변은 BIGO가 허용하는 오디오 송출 경로로 별도 믹스되어야 한다. 앱 내부에서 TTS 소리를 스피커로 틀어 놓았다는 이유만으로 시청자가 듣는다고 주장하지 않는다.
7. 방송 종료 후 전체 음악, 댓글 운영, 예약 상태가 정합성을 유지하며 앱 재실행·네트워크 장애 이후 복원 또는 사용자에게 명확한 재설정 메시지를 제공한다.

## V1.4 개발 범위와 안전 기준
- **현재 실행 중인 원곡 음악**을 지정 분류로 연속재생하고 **5~720분 후 자동으로 재생 종료**한다.
- 사용자가 체크한 경우에만 기존 BIGO 접근성 종료 버튼 시도를 요청한다. 성공 여부를 알고 있다고 표시하지 않는다.
- BIGO 접근성을 댓글 수집용으로 변경하지 않는다. 댓글 자동 대화는 API와 이벤트 구조를 확인한 뒤 별도 동의를 받아 개발한다.
- 승인 없는 무인 시작/종료, 다른 앱 감시, 광고 계정 조작, 댓글 스팸, 외부 서버로 메시지 유출 기능은 포함하지 않는다.
- 사용자 저장 음악·앱 데이터를 파괴하는 자동 업데이트를 하지 않는다. GitHub Actions 임시 디버그 서명키와 기존 APK 서명 호환 문제를 해결하기 전에는 별도 설치 또는 사용자가 보유한 원 서명 키에 의한 안전한 업데이트만 사용한다.

## 실기기 최종 수락 테스트

- 실제 BIGO 오디오 LIVE에서 별도 시청자 휴대폰을 통한 음질·볼륨 0,25,50,100% 비교.
- 1시간 방송 시각, 시작 성공, 종료 성공, 음악 연속재생, 화면 밖 진행 테스트.
- 같은 곡 20분 중복 없음, 이어듣기 실패 시 복귀 처리.
- 한국/중국/서양/연주 각 5곡에서 목록 정합성·원본 음질 확인.
- BIGO 실 댓글(중·한·영), 선물, 팔로우를 통한 자동 답변 품질과 지연/중복/오류 평가.
- 배터리 최적화, Android 16 절전, 접근성 해제, 비행기 모드, BIGO 앱 업데이트 이후 실패 시 안전 종료.

## V1.5 구현 및 중요 제약
- 시간 지정 → Android 로컬 시작 알림 → 사용자 알림 탭 및 확인 → 기존 선택 장르 음악 재생, 재생 종료 타이머 설정, BIGO 앱 오픈.
- 휴대폰이 잠겨 있으면 무인으로 BIGO 방송을 열지 않습니다. BIGO 버튼 접근성 자동조작은 이전과 같이 명시적인 시작 요청에만 시도하고, 실제 생방송 여부를 확인하지 못합니다.
- 5개 언어 × 댓글/선물/팔로우/입장/다음 곡 문구를 화면에서 확인하고 직접 복사하여 붙여넣기. 시청자 댓글 실시간 이벤트 연동 아님.
- Android 13+ 알림 권한 허용이 있어야 예약. 알람은 setAndAllowWhileIdle이라 절전 시 지연 가능하며 재부팅 시 자동 복원은 아직 미지원.
- APP `com.maru.radio.automation` 별도 설치. 기존 앱과 서명 충돌을 피하지만 이전 앱의 곡 목록/설정은 이전되지 않음.

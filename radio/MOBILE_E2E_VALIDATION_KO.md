# MARU 모바일 BIGO 오디오 LIVE 자동 방송 실험 — 검증 기준

상태: **안드로이드 소스 실험판. 실방송 성공 미검증. 일반 사용자 설치용 배포 금지.**
모바일 실제 BIGO에 로그인해서 LIVE 버튼 누름, 송출, 시청자 청취, 실제 라이브 종료를 확인하지 못했습니다.

## 작성된 실험 코드
- 사용자의 한 번의 명시적 동의와 Android 접근성 서비스 별도 활성화.
- BIGO 패키지 sg.bigo.live 화면만 취급. 댓글, 연락처, 비밀번호 저장 및 송신 없음.
- 이전에 선택한 시작·종료 알람에 맞춰 고정된 화면 단계 시도.
- 오디오 라이브 → 믹서 → 마이크 볼륨 1 → Original → 방송하기 → 종료.
- 알 수 없는 화면에서는 동작하지 않음; 90초 뒤 자동화 실패 처리.
- 테스트 경로는 기존 안전형 앱과 분리된 experimental branch.

## 아직 완료가 아닌 이유
1. 제공받은 실제 스크린샷은 UI 글자만 보입니다. BIGO 접근성 트리의 노드/SeekBar 범위/클릭 가능 여부는 확인할 수 없어 UI 자동 누르기가 실기기에선 실패할 수 있습니다.
2. Android 잠금화면·백그라운드 앱 실행 제한은 개발자 권한으로 우회하지 않으며, 예약에서 BIGO 열기 요청이 거부될 수 있습니다.
3. MARU 음악 재생 소리가 BIGO의 방송 입력으로 전달되는지 공식 오디오 연동을 확인하지 못했습니다. 타 앱 미디어 재생만으로 관객이 음악을 듣는다고 할 수 없습니다.
4. 화면에 호스트/시청자 라벨이 있어도 실제 BIGO 서버 송출과 종료는 검증되지 않습니다.
5. 민감 접근성 권한 사용은 별도의 동의 및 Google Play 권한 선언이 필요하며 Play Protect 보호를 해제하는 우회는 하지 않습니다.

## 실방송 최종 완료 체크
- [ ] 실제 갤럭시 S26 울트라에서 동의와 접근성 설정을 정상 허용
- [ ] 오디오 라이브 화면으로 자동 이동 및 믹서 1, Original 설정 실증
- [ ] 예정 시각에 실제 BIGO 라이브 시작, 진행 중 표시 확인
- [ ] 다른 시청자 휴대폰에서 원곡과 볼륨, 전환 청취 확인
- [ ] 종료 시각에 BIGO 서버가 방송 종료됨을 관객 기기에서 확인
- [ ] 잠금/네트워크 오류/절전/버튼 UI 변경 시 안전하게 실패
- [ ] Play Protect 심사 및 안정적인 정식 서명·업데이트 경로 검증

CI에서 Java 유닛 테스트 통과는 실제 BIGO 실기기 라이브 방송 검증과 다릅니다.
실제 사용자의 휴대폰 제어 및 BIGO 계정 방송 세션에 접근할 수 없는 환경에서는
완전 자동으로 실제 방송이 됐다고 주장하거나 합격 APK로 출시해서는 안 됩니다.
기존 V1.7.3 안전형 앱과 저장된 노래는 삭제하지 마세요.

## 2026-10-16 UI 안정화 / Android 오디오 포커스 시도

- 사용자 스크린샷의 믹서가 이미 마이크 1인 경우에는 슬라이더를 다시 건드리지 않고 표시값 1을 확인합니다.
- 믹서 레이어가 여전히 떠 있으면 **방송하기 버튼을 누르지 않습니다**.
- BIGO 전용 접근성 서비스가 이전 실행 후 죽었다면 SharedPreferences의 오래된 connected 플래그를 믿지 않습니다.
- 잠금 화면에서는 BIGO 버튼 조작을 즉시 포기합니다.
- 라벨로 식별된 **보이는 버튼 위치**만 사용자 동의 뒤 눌러, 좌표 추측 의존을 줄였습니다.
- 애니메이션 등의 잦은 접근성 이벤트를 병합해 단계 처리 무한 지연을 방지합니다.
- 이전에는 BIGO가 오디오 포커스를 가져가면 MARU 음악을 pauseOnly()하던 부분에,
  **'BIGO와 음악 동시 재생 시도 (실험)'**이라는 선택 설정을 추가했습니다.
  선택하면 MARU가 배타적인 오디오 포커스 획득을 포기해 동시 재생을 시도합니다.
  Android 제조사/OS/BIGO 앱 정책에 따라 여전히 무음·음질 열화가 가능합니다.
- 이는 **마이크 또는 BIGO 라이브 스트림으로 음원을 주입하는 기능이 아닙니다**.
  다른 앱 재생음을 Android MediaProjection으로 캡처하려면 시스템 사용자 승인이
  필요하며, 캡처가 가능하더라도 BIGO 앱 마이크 입력으로 외부 앱이 역주입하는 것은
  공식 BIGO 제공 입력 경로가 확인되지 않아 완성된 방법이 아닙니다.
- BIGO 공식 오디오 라이브 안내는 앱 안의 방송 모드와 믹서/배경 음악을 소개하지만,
  외부 앱의 사전 녹음된 음원 수백 곡을 BIGO Audio LIVE 내부 오디오 입력으로 전달하는
  공개 SDK/인텐트를 제공한다고 명시하지 않습니다.

검토 자료:
- https://www.bigo.tv/blog/audio-live-bigo-live
- https://developer.android.com/media/platform/av-capture

이전처럼 CI APK가 **BUILD SUCCESS**만 보여도 실제 BIGO 오디오 라이브 시작·수신·종료까지
검증한 것은 아닙니다. 이 실험은 검증되지 않은 새로운 접근성 권한을 요구하므로,
Play Protect에 의해 차단되면 우회하지 말고 안전형 V1.7.3을 계속 사용해야 합니다.

## 2026-10-16 갤럭시 실기기용 안전 진단 기능 추가

- 방송 예약 화면에 **'🔍 BIGO 화면 안전 진단 (방송 시작 안 함)'** 버튼 추가.
  이 기능은 별도 동의/Android 접근성 연결이 있는 경우에만 작동합니다.
- BIGO 앱을 열어 **최대 60초간 현재 화면의 접근성 기능 지원 여부를 읽기 전용으로 검사**.
  실제 방송하기 또는 종료 버튼을 누르지 않습니다.
- 방송 준비 화면, 믹서, 마이크 볼륨 1 표시, 믹서·방송하기·Original 레이블,
  RangeInfo를 포함한 슬라이더 개수만 **BIGO 앱 내부 상태로 로컬 보관**합니다.
  원시 화면 텍스트, 방 이름, 댓글, 시청자 정보는 저장/전송하지 않습니다.
- 앱으로 돌아오면 **BIGO 자동 조작 동의/접근성/최근 상태** 부분에 익명화한
  진단 결과가 표시됩니다. BIGO의 실제 API/레이아웃에 이 정보가 노출되지 않으면
  알 수 없다고 표시합니다. 그 자체가 방송 완료나 실제 송출 확인은 아닙니다.
- Original 오디오 효과가 이미 Android 선택 상태인 경우 재클릭 없이 유지하도록 개선.
- 설정한 시간에 BIGO 시작/종료 UI가 예상과 달라 중단될 때는 (알림 권한 허용 시)
  **'BIGO 방송 시작/종료 상태 확인 필요'** 휴대폰 알림을 보냅니다.
- 설정 화면에서 접근성 자동화 동의를 철회하면 예약 UI 조작 콜백을 즉시 취소합니다.

### 현재 실기기 검증이 불가능한 범위

GitHub Actions에서 실제 갤럭시 기기, 개인 BIGO 로그인 세션, 다른 시청자
오디오 수신을 가져올 권한은 제공되지 않습니다. 따라서 진단 UI를 추가하고
빌드 테스트에 합격해도 BIGO 방송 성공이나 자동 종료를 증명할 수 없습니다.

사용자가 보내준 BIGO **이미지**는 도움 되지만 접근성의 노드 계층
또는 실제 **오디오 입력 파이프라인**에 대한 정보를 담지 않습니다.
휴대폰에서 읽기 전용 진단과 타계정 청취/종료 검증이 완료되어야만
배포 가능한 완성본이라고 판정할 수 있습니다. 민감 권한이 추가된
실험판을 Play Protect 경고를 우회해 설치해서는 안 됩니다.

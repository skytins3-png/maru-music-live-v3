# MARU 모바일 BIGO 오디오 LIVE 자동 방송 실험 — 검증 기준

상태: **안드로이드 소스 실험판. 실방송 성공 미검증. 일반 사용자 설치용 배포 금지.**
모바일 실제 BIGO에 로그인해서 LIVE 버튼 누름, 송출, 시청자 청취, 실제 라이브 종료를 확인하지 못했습니다.

## 작성된 실험 코드
- 사용자의 한 번의 명시적 동의와 Android 접근성 서비스 별도 활성화.
- BIGO 패키지 sg.bigo.live 화면만 취급. 댓글, 연락처, 비밀번호 저장 및 송신 없음.
- 이전에 선택한 시작·종료 알람에 맞춰 고정된 화면 단계 시도.
- 오디오 라이브 → 믹서 → 마이크 볼륨 1 → Original → 방송하기 → 종료.
- 알 수 없는 화면에서는 동작하지 않음; 90초 뒤 자동화 실패 처리.
- 테스트 경로는 기존 안전형 앱과 분리된 experimental branch.

## 아직 완료가 아닌 이유
1. 제공받은 실제 스크린샷은 UI 글자만 보입니다. BIGO 접근성 트리의 노드/SeekBar 범위/클릭 가능 여부는 확인할 수 없어 UI 자동 누르기가 실기기에선 실패할 수 있습니다.
2. Android 잠금화면·백그라운드 앱 실행 제한은 개발자 권한으로 우회하지 않으며, 예약에서 BIGO 열기 요청이 거부될 수 있습니다.
3. MARU 음악 재생 소리가 BIGO의 방송 입력으로 전달되는지 공식 오디오 연동을 확인하지 못했습니다. 타 앱 미디어 재생만으로 관객이 음악을 듣는다고 할 수 없습니다.
4. 화면에 호스트/시청자 라벨이 있어도 실제 BIGO 서버 송출과 종료는 검증되지 않습니다.
5. 민감 접근성 권한 사용은 별도의 동의 및 Google Play 권한 선언이 필요하며 Play Protect 보호를 해제하는 우회는 하지 않습니다.

- [ ] 종료 시각에 BIGO 서버가 방송 종료됨을 관객 기기에서 확인

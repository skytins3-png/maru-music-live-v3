# MARU RADIO — 개인정보 및 접근성 기능 고지 초안

최종 갱신: 2026-10-16. Google Play 등록용 공개 개인정보처리방침 초안입니다.
실제 앱 동작과 사용자 운영 방식, 연락 방법이 확인되어야 공식 개인정보처리방침으로 공개할 수 있습니다.

## 목적
MARU RADIO는 사용자가 직접 선택한 음악을 Android에서 재생하고 사용자가 직접 지정한 시각에 시작·종료를 예약하며, 사용자가 허용한 경우에만 BIGO 오디오 라이브 화면의 제한된 버튼을 조작하려는 실험 기능을 제공합니다.

## Android AccessibilityService 사용
- 앱의 접근성 서비스를 사용하려면 사용자에게 기능 사용 이유와 범위를 알린 후 별도 동의가 필요합니다.
- Android 설정에서 서비스를 사용자가 직접 켜야 합니다. 앱은 기기 설정·잠금·보호 기능을 우회하지 않습니다.
- 이 기능은 **장애인 지원 접근성 도구가 아니라**, 사용자가 지정한 시각에 BIGO 오디오 라이브 준비 화면, 믹서, 시작 및 종료 확인 버튼의 **제한된 고정 단계**를 실행하려는 자동화입니다.
- BIGO 패키지(`sg.bigo.live`) 밖의 앱 화면을 수집하지 않으며 UI 제어 요청은 90초 안에 만료됩니다.
- 접근성 트리에서 버튼, 효과 종류, 마이크 숫자 1 등 필요한 **고정된 화면 레이블**만 확인합니다. 메시지·비밀번호·시청자 이름·연락처 등의 원문을 데이터베이스 또는 외부 서버로 전송하지 않도록 설계되었습니다.
- 실패/기기 잠금/버튼 UI 불일치 시 동작을 멈추며 사용자에게 앱 상태를 알립니다. 사용자는 동의를 언제든 철회할 수 있습니다.
- 접근성 서비스 사용으로 앱의 BIGO 방송 시작/종료와 청취자 음질을 보장하는 것은 아닙니다. 이 기능은 BIGO 공식 SDK 인증을 받은 기능이 아닙니다.

## 로컬 데이터
등록한 원곡의 제목/URI 참조와 중복 확인 SHA-256 해시, MARU 재생설정, 사용자가 직접 가르친 AI 진행자 문구, 요청곡 집계, 직접 선택한 녹음 인사 파일 URI는 사용자 단말기에 저장합니다. 별도 업로드·판매·광고 용도로 이용하지 않습니다. 원본 Download 파일은 자체 삭제 기능의 기본 대상이 아닙니다.

## 접근 권한
- 음악 폴더: Android 시스템 문서 선택기로 선택한 항목을 읽는 목적으로만 사용합니다.
- 알림: 예약 음악 재생/방송 종료 확인 결과를 알립니다.
- 정확한 알람: 사용자가 선택한 시각에 MARU 음악 재생/종료를 요청하기 위해 사용합니다.
- 접근성: 사용자가 동의한 좁은 목적의 BIGO 화면 탐색 및 버튼 동작을 위해 사용합니다.
- 선택적 음성 입력: Android에 설치된 별도 음성 인식기 대화창을 사용하며, 그 서비스의 개인정보 처리 여부는 선택된 음성 인식 앱의 정책에 따릅니다.

## 데이터 관리
사용자는 앱의 학습 기록 초기화 버튼으로 학습 횟수와 직접 가르친 문장을 삭제할 수 있습니다. 앱의 데이터 삭제/삭제는 해당 앱 내부의 설정·참조 데이터를 삭제할 수 있으며 외부 Download 원본은 별도로 보존됩니다.

앱 이용 약관, BIGO 이용 조건, Play Console 데이터 안전 양식/접근성 기능 사용 신고, 실제 접근성 트리 및 BIGO 청취자 오디오 기능의 점검이 필요합니다. 이 문서가 자동으로 Google Play 승인을 의미하지 않습니다.

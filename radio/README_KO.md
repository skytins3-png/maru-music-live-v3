# MARU RADIO V1.5 — Suno 원곡 전용 초경량 앱

이 앱은 이전 MARU MUSIC LIVE APK의 이름/아이콘만 바꾼 것이 아닙니다. 별도 Android 모듈 `radio/`에 자체 Activity와 원곡 보관 로직을 새로 작성했으며 외부 Android 라이브러리가 없습니다.

## 프로그램 사용

1. **Suno 열기**에서 본인 원곡을 만든 뒤 MP3/WAV를 정식으로 휴대폰에 다운로드합니다.
2. **원곡 파일 가져오기**를 눌러 MP3/WAV를 1곡 이상 선택합니다. 또는 내 파일 앱에서 곡을 선택해 **공유 → MARU RADIO**로 보냅니다. Suno의 **링크 공유만으로는 음원 파일이 전달되지 않습니다.**
3. 앱은 음악 파일을 변경하지 않고 사본을 저장합니다. 완전히 동일한 음악 파일은 SHA-256으로 중복 보관하지 않습니다. 목록에서 **미리듣기**를 눌러 확인합니다.
4. **BIGO용 저장**을 누르면 표준 Android 파일 저장 화면이 나옵니다. 사용자가 원하는 폴더(예: Music)를 선택하여 원곡을 바이트 그대로 저장합니다.
5. **BIGO LIVE 열기**를 누르고 BIGO **오디오 LIVE**를 직접 시작합니다. BIGO 방송 도구의 음악/믹서에 **휴대폰 로컬 음악 선택**이 표시되는 경우 해당 원곡을 선택하고 방송 음량을 BIGO에서 조절합니다. 메뉴가 없다면 원곡을 강제로 주입할 수 없습니다.

## 핵심 한계

- **Suno 앱에서 즉시 재생하는 소리를 BIGO LIVE로 직접 주입하는 기능은 없습니다.** Android의 통상적인 앱 권한으로 제3자 방송 앱의 마이크 입력을 대체하거나 화면 밖에서 해당 앱의 내부 믹서를 조작할 수 없습니다.
- BIGO가 자체 배경음악으로 로컬 오디오를 입력하는 것을 허용하는 경우, 휴대폰 볼륨키와 시청자 방송 음량을 분리할 수 **있는지** 확인합니다. 원곡이 BIGO 송출에 전달되거나 휴대폰 볼륨 0%에서 방송이 유지된다고 이 앱이 보장하지 않습니다.
- BIGO 공식 앱 설명에는 방송 중 기기 내 음악/오디오 파일 사용 권한이 소개되어 있으나, 실제 로컬 파일 선택 UI는 국가·버전·계정·오디오 LIVE 모드에 따라 다를 수 있습니다.
- 마이크 녹음, 오디오 가로채기, 강제 송출, 숨김 권한, 접근성 자동 조작 기능이 없습니다.

## 업데이트 및 개인정보

- `com.maru.radio.player` 새 앱으로 설치되므로 기존 MARU MUSIC LIVE를 삭제하거나 교체하지 않습니다.
- 저장한 음원 사본은 앱 전용 저장소에 있습니다. MARU RADIO 앱 삭제 시 이 사본은 사라지지만 원래 Suno 다운로드 파일 및 BIGO용으로 저장한 파일은 유지됩니다.
- 이전 MARU의 노래 목록/설정은 자동으로 가져오지 않습니다. 기존 앱 그대로 두고 새 앱을 사용하세요.

## 시험

- BIGO의 **시청자 측 음량**은 반드시 다른 기기로 듣고 비교해야 합니다. 휴대폰 볼륨 0%, 25%, 50%, 100%에서 동일한지 확인하고, Suno 원본 앱 직접 재생과 BIGO 내장 음악 재생은 구분합니다.
- GitHub Actions `MARU RADIO V1 lightweight Android APK`에서 신규 앱만 독립적으로 빌드하고 정적 정책 검사/Android Lint/서명검증을 수행합니다.

## V1.1 원곡 192곡 일괄 가져오기 및 정리
- **Download 바로가기**: Android 오디오 파일 선택기가 가능한 경우 Download 폴더에서 바로 열리도록 시작 위치 지정 (DocumentsUI 지원 여부에 따라 마지막 열었던 위치가 표시될 수 있음).
- **다른 폴더에서 가져오기**: Music/Suno/내 파일 등 다른 위치 선택 지원.
- **192곡 이상 다중 선택**: SHA-256으로 파일 내용이 완전히 일치하면 1곡만 보관합니다. 내용이 다르면 같은 제목이어도 다른 원곡으로 간주합니다. 진행 건수/신규/중복/오류 표시.
- **검색/정렬/체크/선택 삭제**: MARU가 보관 중인 사본만 삭제하며 원래 Download 파일이나 Suno 보관함은 절대 건드리지 않습니다.
- **같은 제목 후보 확인**: 이름만 같고 내용이 다른 편곡/버전을 보여줘 사용자 판단으로 삭제할 수 있게 함. 파일이 완전히 같은 중복곡은 이미 가져오기 단계에서 제외됩니다.
- **새 앱 ID** `com.maru.radio.player`: 기존 MARU RADIO V1 설치/곡 보관함/원곡을 삭제하지 않고 별도 설치합니다. 다른 앱의 내부 원곡 보관 목록은 자동으로 가져올 수 없으므로 다운로드 폴더에서 다시 불러오세요.

### Download 저장공간 사용
파일 선택기(ACTION_OPEN_DOCUMENT)로 고른 오디오는 가능한 경우 원래 Download 파일에 대한 **읽기 전용 접근 권한만 지속 저장**하며 재복사하지 않습니다. Android의 읽기 권한 보관 제한(오래된 Android에서 128개)에 대비해 96개 이후 혹은 지속 권한 지원이 안 되는 제공자는 앱 내부에 바이트 그대로 사본을 저장합니다. 내 파일에서 ‘공유’로 보낸 음악은 별도 사본을 저장합니다. 삭제 버튼은 다운로드 원본 파일을 삭제하지 않고 MARU 목록/보관 사본만 지웁니다.

## V1.2 원곡 재생 버튼/서비스
- 첫 화면 최상단에 **⏮ 이전 / ▶ 재생·⏸ 일시정지 / 다음 ⏭ / ■ 재생 종료** 및 재생 시간 탐색바와 현재 곡명이 크게 표시됩니다.
- 원곡 목록의 ▶ 또는 첫 화면 재생 버튼으로 음악을 틀 수 있으며 곡 종료 시 다음 곡을 이어서 재생합니다.
- Android 미디어 전용 Foreground Service로 전환해 BIGO나 다른 앱 화면을 열어도 음악 **재생 서비스 자체는 계속 실행**하도록 했습니다. 운영체제 오디오 포커스 제한·BIGO의 마이크/음악 혼합 정책에 따라 음악이 중지/감소할 수 있으며 BIGO 송출은 별도 입력이 필요합니다.
- 스마트폰 볼륨키를 통해 출력되는 일반 미디어 볼륨이며 BIGO 시청자에게 일정한 방송 볼륨으로 전송한다는 보장은 없습니다.
- 과거 GitHub 빌드 APK와 서명이 달라 덮어쓰기 실패 가능성이 있어 설치 ID는 `com.maru.radio.player` **새 앱**으로 구분했습니다. 이전 MARU RADIO 곡관리의 개인 데이터/곡 목록은 자동 이전되지 않습니다. **기존 앱의 원곡 목록/데이터를 지우지 마세요.** Download 폴더에서 다시 불러오기 바랍니다.


## V1.3 BIGO 방송 시작·종료 지원 (사용자 동의 전용)

첫 화면 플레이어 아래에는 ‘▶ 방송 시작 지원’과 ‘■ 방송 종료 지원’ 버튼이 있습니다.
형이 버튼을 눌러 확인한 경우에만 BIGO 화면을 열어 버튼을 찾습니다.

이 기능은 BIGO 공식 원격 API가 아니라 **Android 접근성 제어 보조기능**입니다.
BIGO 오디오 LIVE를 직접 시작/끝내는 제어 API는 확인되지 않았습니다.
따라서 BIGO UI 버전, 텍스트 접근성, 화면 위치에 따라 작동하지 않거나
최종 방송 상태를 알 수 없습니다. BIGO에서 화면을 반드시 확인하세요.

### 최초 허용

‘BIGO 접근성 지원 설정 / 상태 확인’에서 권한 설명을 읽은 뒤, 사용자가 원하는 경우에만
휴대폰 **설정 → 접근성 → 설치된 앱 → MARU BIGO 방송 버튼 지원**을 직접 켭니다.
이 권한은 화면을 읽고 버튼을 누를 수 있는 강한 권한이므로 신뢰하는 앱에만 허용하세요.
언제든 설정에서 해제할 수 있으며, 알림/채팅/계정정보를 서버로 수집하거나
다른 앱을 감시하는 기능이 아닙니다. BIGO 패키지 `sg.bigo.live`만 접근 가능하며
사용자가 시작·종료 버튼을 누른 **최대 60초 동안만** 조작합니다.

### 화면별 동작

- 시작: BIGO 홈 → 방송 준비 화면 열기 → ‘오디오 라이브’ 선택 → ‘방송하기’ 클릭.
  화면 요소를 인식하지 못하는 단계는 형이 직접 눌러야 합니다.
  BIGO 방송을 시작하는 동작이므로 MARU에서 명시적인 확인 팝업 후에만 진행합니다.
- 종료: 라이브 진행 화면을 확인한 다음 상단 종료 X → ‘라이브 종료하기’.
  화면 요소가 없거나 잘못된 페이지라면 자동 조작을 멈추고 직접 조작하도록 안내합니다.
  종료도 MARU에서 명시적인 확인 팝업 후에만 진행합니다.

**주의:** 화면에서 인식 가능한 글자/버튼과 Galaxy 화면 비율의 제한적인
홈/종료 터치에 의존하므로 실제 기기에서 완료 여부를 보장할 수 없습니다.
프로그램은 생방송 여부를 BIGO 서버에 질의하지 못합니다.
기존 MARU RADIO V1.2는 유지되며, 새로운 앱 ID
`com.maru.radio.bigo`로 별도 설치됩니다. 기존 다운로드 음원은 보존되나
개인 앱 목록은 새 앱에 다시 등록해야 합니다. 이전 앱 삭제 금지.

Suno 앱 직접 소리를 BIGO에 볼륨 독립적으로 넣는 기능과 방송 시작/종료는
서로 다른 문제입니다. 이 버전은 방송 컨트롤 보조 기능만 추가한 것입니다.


## V1.4 방송 편성: 장르별 자동 연속재생 및 종료 타이머

- 4개 분류: 한국노래 / 중국노래 / 서양노래 / 연주곡, 전체 음악 선택 가능. 재생대기열은 선택한 분류만 자동 이어듣기하며 곡 끝에 순환 재생합니다.
- 기존 저장곡 제목으로 **한국어/중국 한자/라틴 문자/연주 문구**를 우선 추정하되, **음악을 들어서 분류하는 AI 기능은 아닙니다**. 곡의 ⋮ → 곡 분류 변경으로 직접 고칠 수 있습니다.
- **방송 시간 · 자동 종료** 버튼에서 5~720분을 입력해 해당 시간이 지나면 MARU 음악 서비스 종료. 예약한 종료시각의 남은 시간 표시. 음악 재생 상태에서 설정하는 타이머이며, 앱이 종료/기기 재부팅되면 OS의 재생 서비스 생존 정책에 따라 실행이 중단될 수 있습니다.
- BIGO 종료 요청은 **사용자가 타이머 설정 당시 명시적으로 체크한 경우만** 도구 내 기존 접근성 지원을 사용해 시도하며, BIGO 화면 상태와 UI 버전에 따라 실제 종료가 실패할 수 있습니다. 시청자 관점에서 종료 확인이 필수입니다.
- **시계로 설정한 미래 시각에 BIGO 라이브를 저절로 시작하는 기능은 아직 없습니다.** 라이브가 시작될 것처럼 알람을 표시하지 않습니다.
- **댓글을 자동 읽고 자연스럽게 대화하거나 채팅으로 전송하는 기능은 아직 없습니다.** BIGO 플랫폼이 제공하는 검증 가능한 댓글 데이터 입력과 시청자 동의·필터·언어·중복 응답·송출 오디오 경로가 필요합니다.
- 다른 음악 방송 앱과 독립적으로 신규 ID `com.maru.radio.program`을 사용해 기존 사용자 음원/기록을 보호합니다. V1.3 앱의 내장 음악 목록/설정은 자동 이전되지 않으니 Download에서 가져오세요.


## V1.5 실제 구현: 방송 시작 알림과 다국어 답변 준비
- MARU RADIO 편성 카드의 **시작 시각 예약 · 다국어 댓글 답변** 버튼을 누르면 별도 간단한 화면을 엽니다.
- 원하는 **시작 시각(HH:mm)**을 선택하면 로컬 Android 알람(`AlarmManager.setAndAllowWhileIdle`)을 예약합니다. 별도의 정확한 알람 권한을 요구하지 않는 대신, **절전/Doze 상태에서 몇 분 늦을 수 있습니다**.
- Android 13+에서는 알림 허용을 요청합니다. 허용하지 않았다면 예약되지 않았다고 안내합니다.
- 예약 시간에 알림이 표시되면 **사용자가 직접 탭하고 확인한 뒤** 해당 분류 Suno 음악 재생 + BIGO 앱을 여는 시도를 합니다. 기존 BIGO 접근성 지원을 켜 둔 경우에만 BIGO의 시작 버튼 누르기도 시도합니다. **잠금 화면에서 무인 자동 방송 시작이 아닙니다**.
- 현재 V1.4의 재생 5~720분 종료 타이머를 유지합니다. 휴대폰의 OS가 백그라운드 음악 서비스를 종료한 경우, 분 단위 자동 종료 보장은 없습니다.
- 5개 언어(한/중/영/일/러) × 5개 상황(환영/댓글/선물/팔로우/다음 곡)의 **확인 후 복사** 문구를 제공합니다. BIGO 댓글 자동으로 읽기/전송/음성 송출은 구현되지 않았으며, 앱에서 선택해서 붙여넣는 방식입니다.
- 앱 ID `com.maru.radio.automation`으로 이전 V1.4와 별도 설치되며, 이전 앱의 노래 저장 목록이 자동 이전되지는 않습니다. 반드시 Download의 원곡을 다시 등록하세요. 기존 앱을 삭제하지 마세요.
- **BIGO 실 방송에서 확인해야 하는 문제:** 라이브 시청자에게 음악이 실제 나가는지, 휴대폰 볼륨과 방송 소리가 독립인지, 시작/종료 클릭 접근성이 화면 업데이트 후 유지되는지.

## V1.5 음악 장르 자동 순환
- 방송 편성에서 **4장르 자동 순환**을 선택하면 한국노래→중국노래→서양노래→연주곡 순으로 원곡을 한 곡씩 섞어 재생합니다. 비어 있는 분류는 자동 건너뛰며 같은 파일을 다시 복사하지 않습니다.

## V1.6.1 → V1.6.2 기존 앱 덮어쓰기 업데이트 문제 (2026-10-19 검증)

- Android 업데이트는 **동일한 applicationId, 호환되는 서명 인증서, 더 높은 versionCode**가 필요합니다. `V1.6.2`의 `versionCode 9`는 `V1.6.1`의 `versionCode 8`보다 높지만 **서명이 다르면 업데이트 실패**입니다. 특정 휴대폰의 실제 설치본 인증서는 이 저장소에서 자동으로 알 수 없습니다.
- **기존 앱을 삭제하거나 Play Protect 경고를 우회하지 마세요.** 앱 내 재생목록, 설정, 사용자가 앱에 복사해 둔 음원 데이터가 삭제될 수 있습니다. `Download` 폴더의 원본은 별개지만 삭제 전 확인 없이 데이터 보존을 약속할 수 없습니다.
- 안전한 향후 릴리스용 GitHub Actions `radio-matching-signer-update.yml`을 추가했습니다. 현재 설치 앱의 **원래 서명 개인키(keystore)를 소유자가 보유하고 있는 경우에만** GitHub Actions Secrets에 주입합니다. 이를 통해 **현재 설치본의 인증서 SHA-256**과 새 서명을 확인하여 완전히 일치할 때만 `SAME-SIGNER-UPDATE` 아티팩트를 만듭니다. 키가 없거나 지문이 다르면 파일 생성 전에 실패하며 어떤 앱도 자동 제거하지 않습니다.
- GitHub Actions Secrets: `MARU_RADIO_ORIGINAL_KEYSTORE_BASE64`(개인 키 저장소의 base64), `MARU_RADIO_ORIGINAL_STORE_PASSWORD`, `MARU_RADIO_ORIGINAL_KEY_ALIAS`, `MARU_RADIO_ORIGINAL_KEY_PASSWORD`. **채팅, 공개 이슈/PR, 커밋에 키나 비밀번호를 보내지 마세요.**
- 이 방법은 원본 키 없이 기존 패키지를 강제로 덮어쓰는 우회가 아닙니다. 원래 키를 확보할 수 없다면 현재 설치본의 보존 및 추후 새 설치 시 데이터 이전 계획을 별도로 세워야 합니다. GitHub Actions 임시 debug 서명키를 릴리스 업데이트용으로 사용해서는 안 됩니다.


## V1.6.3 · 자동 1시간 종료 제거 / BIGO 동시 재생 보완 (2026-10-28)

- **기본 자동 종료는 꺼짐**: 기존 V1.6.x에서 60분이 초기값으로 저장되어 있어도 신규 예약 시작이 자동 타이머를 걸지 않습니다. 기본은 음악 무제한 연속 재생입니다.
- **명시적 타이머만 사용**: 사용자가 '종료시간 직접 설정'에서 5~720분을 지정하면 그때부터 음악 종료 타이머가 활성화되고 다음 예약 시작 시에도 해당 선택이 적용됩니다. '타이머 취소'는 진행 중인 음악 타이머를 해제하고 다음 예약 시작에 쓰일 자동 종료 선택도 끕니다.
- **BIGO 화면 이동 전 포커스 양보**: MARU 음악 서비스가 실행 중인 경우 Android 오디오 포커스를 내려놓고 BIGO 앱을 엽니다. 일반 음악 재생 상태의 일시적 포커스 중단 후 복귀 처리도 보완했습니다.
- **잠금 화면 재생 유지 보완**: 음악 재생 중 MediaPlayer가 부분 Wake Lock을 관리합니다. 휴대폰 절전 정책이나 다른 앱의 독점 오디오 모드는 여전히 재생에 영향을 줄 수 있습니다.
- Android 10 이상에서 원본 음악 출력의 **허용 가능한 시스템 캡처 정책**을 선언합니다. BIGO가 해당 음원을 받아서 마이크/청취자 쪽으로 전달하는지는 BIGO 자체 정책 및 UI/믹서 지원에 달려 있습니다.
- **BIGO 실제 무인 시작/종료, 마이크/믹서 자동 조작, 실시간 댓글 수집 및 AI 자동 응답은 구현된 기능이 아닙니다.** 접근성 권한·자동 클릭 없이 사용자가 BIGO에서 시작/종료를 누르도록 유지합니다.
- 업데이트를 위해 앱 ID는 `com.maru.radio.safev16` 그대로이고 버전은 `1.6.3`입니다. CI가 생성하는 디버그 키 서명으로는 기존 설치본과 **서명이 다를 수 있으니 삭제하거나 덮어쓰기 전에 원곡 데이터 및 서명 일치를 반드시 확인**해야 합니다.

### 재현 시험 순서
1. MARU RADIO를 열어 Suno MP3/WAV 원곡을 직접 추가하고 4장르 자동 순환을 선택합니다.
2. '타이머 취소'를 누른 상태에서 재생 → BIGO 열기 → 화면 잠금/앱 전환 → 다음 곡 자동 전환까지 확인합니다. **60분 경과 후에도 MARU 음악이 재생**되는지 별도로 확인합니다.
3. '종료시간 직접 설정'에서 5분을 켜 음악만 종료되는지, BIGO 실제 방송은 자동 종료되지 않는지 확인합니다.
4. 5분 타이머를 취소하고 시작 시각 알림을 설정해 알림을 누른 뒤 방송 재생을 선택합니다. 이전 종료 타이머가 자동으로 다시 시작되지 않아야 합니다.
5. BIGO 자체 음악/믹서에서 **기기 로컬 음원 입력 가능 여부**를 확인하고 별도의 청취자 휴대폰에서 출력 볼륨 0/25/50/100% 비교를 실시합니다. 불가능한 입력 경로는 '지원 안 됨'으로 기록합니다.

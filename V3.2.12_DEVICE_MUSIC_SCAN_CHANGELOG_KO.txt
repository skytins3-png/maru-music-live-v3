MARU MUSIC LIVE V3.2.12 · 휴대폰 전체 음악 자동 검색

1. 처음 한 번만 음악 접근 권한을 요청합니다.
2. 앱을 열 때 Android MediaStore에서 휴대폰 전체 음악을 다시 찾습니다.
3. "휴대폰 전체 노래 자동 불러오기" 버튼으로 언제든 수동 재검색할 수 있습니다.
4. 동일한 파일 내용(SHA-256)은 목록에 한 곡만 남깁니다.
5. 제목만 같고 실제 파일 내용이 다른 곡은 그대로 유지합니다.
6. 원본 노래 파일은 이동·변경·삭제하지 않습니다.
7. 기존 직접 선택 방식은 "노래 직접 추가"로 계속 사용할 수 있습니다.

안전 범위
- 자동 삭제 없음
- 자동 업로드 없음
- 자동 구매·자동 배포 없음
- 재검색 중 재생 중인 곡은 목록이 바뀌는 경우에만 안전 정지

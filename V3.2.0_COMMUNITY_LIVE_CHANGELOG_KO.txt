MARU MUSIC LIVE V3.2.0 변경사항

- 게임 LIVE를 기본 방송 방식에서 제외
- 일반 LIVE 음악방송 시작 버튼 추가
- 오디오 LIVE 음악방송 시작 버튼 추가
- 기존 V3.1.6 PlaybackService 유지
- MARU 음악을 먼저 시작한 뒤 BIGO LIVE 실행
- BIGO 방송하기는 사용자가 직접 누름
- 메인 화면의 OCR 번호 버튼과 개발용 버튼 제거
- 개발 기능은 오류검사·고급 기능 대화상자로 이동
- 가짜 댓글·마이크·카메라·소통·상점 UI 생성하지 않음
- 게임 LIVE는 고급 기능의 보조 모드로 유지
거절 정책은 학습으로 바뀌지 않습니다

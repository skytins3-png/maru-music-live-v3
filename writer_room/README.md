# MARU RADIO 제작국 — 가수/방송진행자와 분리된 전문작가팀 (WR-01..05)

## 고유 명단 (2026-11-08)
- WR-01 **문세필**: 방송 총괄/구성, 편성, 기승전결, 큐시트
- WR-02 **차율담**: 장르/전통악기/음악 조사, 음원 확인
- WR-03 **백지온**: 뉴스/날씨/역사/생활정보 조사와 사실 검증
- WR-04 **손다솜**: 청취자 승인 사연, 사연 각색 시 동의·익명화
- WR-05 **구재담**: 재미/자연스러운 말투/중복 회피/방송 전 최종 검수

## 엄격한 분리
1. 작가 5명은 `WriterRoomCatalog`에만 등록. 기존 `VirtualArtistCatalog` (현재 소스에 등록된 32 캐릭터) 및 Suno 가수 설정을 **절대 변경하지 않음**.
2. 작가는 방송에 출연하지 않음. 아환·윤솔과 실제로 지정된 가상 가수만 대본을 진행하며, 기존 가상 가수의 **노래 파일 존재는 별도 검증**.
3. 작가에게 임의의 AI 가창/음성 복제 기능을 주지 않음. 기존 음성 파일이나 방송인 실명은 사용하지 않음.
4. 출처 없는 뉴스/날씨, 허위 댓글/선물, 실제로 없었던 청취자 사연을 지어내지 않음. 실시간 정보는 검증한 시간과 출처를 첨부.
5. 실시간 웹조사, 모델별 독립 실행, 자율 학습은 아직 **구현되지 않음**. 이 파일은 작가 역할, 검수 기준, 샘플 대본의 코드 초기 구현.
6. 기존 방송 APK에는 **반영되지 않음**. PR 검증 후 별도 설치본과 실제 음성 재생/BIGO 송출 확인 필요.

## 5단계 제작 절차
1. WR-01 편성 지시: 주제, 장르, 대본 목표 러닝타임, 곡 순서.
2. WR-02/03 자료 조사: 공식 자료 우선, 1차 출처/발행 시각/라이선스/추가 검증 기록.
3. WR-04 대화 및 사연 각색: 인물 동의, 익명화, 주제에 맞는 진솔한 대사.
4. WR-05 교정: 반복 제거, 어색한 AI 말투, 허위 사실/저작권/차별 표현 검사.
5. WR-01 최종 승인: 편집본 확정 후 아환/윤솔에게 대본 큐만 전달. 곡 파일 없으면 음악 큐 대기/건너뛰기.
